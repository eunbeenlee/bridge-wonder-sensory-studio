# Bridge Wonder V14 — V12 그래픽 복원 + V13 동의 기능 유지

## 적용 범위
- 화면·로고·일러스트·기본 색감·카드 스타일은 **V12**를 기준으로 복원했습니다. `assets/img/`의 모든 이미지 파일은 V12와 **SHA-256까지 동일**합니다.
- V13의 동의 기능을 유지했습니다: 필수 4항목 + 선택 5항목, 전체 동의, 필수만 동의, 개별 선택/철회 기록, PDF/Google Sheets 항목별 저장.
- 마지막 전자서명 동의는 전체 동의 대상에서 제외했습니다.
- 읽기 불편했던 '등록 전 확인 사항 코드' 등을 자연스러운 한국어로 고쳤습니다.
- 기존 Apps Script `/exec` 주소, 상담 접수 데이터, 아카데미 저장소와 DNS 설정은 변경하지 않습니다.

## 가장 간단한 배포 순서
1. **Google Apps Script**: 기존 Code.gs 백업 → 이 패키지의 AppsScript/Code.gs로 전체 덮어쓰기 → 저장 → `setupEnrollmentV13` 한 번 실행 → 기존 웹 앱 `배포 관리`에서 **기존 배포를 새 버전으로 갱신**. (새 배포 URL 생성 불필요)
2. **GitHub**: GitHub_Website/ 폴더 안의 파일 전체를 `eunbeenlee/bridge-wonder-sensory-studio` 저장소 최상위에 덮어쓰기 → Commit → Push. `.git` 삭제 금지.
3. 테스트: 기존 서식의 등록 코드로 수강 조건 불러오기, 선택 동의 **0/5** 상태에서도 필수 동의+서명 제출, 전체 동의/필수만 동의 전환, 스프레드시트 개별 선택 결과와 PDF 기록 확인.
4. 실제 배포 전에는 보호자 이메일·서명·PDF 보관과 자동 백업이 계정에서 정상 작동하는지 실데이터 대신 **테스트 인적사항**으로 확인하세요.

## 주의할 점
- 실제 등록은 현장 상담 후 직원이 발급한 개별 링크로 진행합니다. 방문·문의와 다릅니다.
- `전체 동의`는 **선택사항까지 묶어 선택하는 편의 기능**입니다. 선택 동의 거부로 등록을 막아서는 안 됩니다.
- 촬영/활용 동의 기록과 동의 철회 이력은 서로 구분하여 운영하세요.
- 법정대리인 확인, 실제 교습비·반환 규정, PDF 교부, 영수증과 법정 장부 확인은 실제 운영자가 별도로 수행해야 합니다.
- Google Sheets·Drive 백업과 개인정보 보관기간은 운영계정에 적절한 접근권한을 설정하고, 실제 법령·교육청 신고내용과 대조해야 합니다. 이 패키지만으로 법적 준수가 완료되었다고 볼 수 없습니다.

## V12 시각 자산 고정
기존 V12 이미지 10개를 모두 동일하게 사용하며 V13 생성 이미지나 외부 스톡 사진을 추가하지 않았습니다. `assets/css/site.css`는 V12 원본 + 동의 화면에만 필요한 V13 접근성·선택 UI 스타일입니다. V13의 전역 그래픽 필터(채도 저하), 히어로 배경과 카드 그림자 변경은 적용하지 않습니다.
