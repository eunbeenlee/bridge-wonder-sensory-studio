# Bridge Wonder V49 · 개인사업자 운영 손익·현금흐름

기준일: 2026-11-21. 개원 준비 기준: 2027년 1월, 생후 7~48개월 아이 4명+보호자 4명, 50분 수업. 계산 기능은 **원장(owner) 전용**입니다.

## 1. 입력된 실제/예상값

| 항목 | 초기값 | 상태 |
|---|---:|---|
| 상가 임대보증금 | 10,000,000원 | 사용자 제공, 계약서 재확인 |
| 월 임차료 | 700,000원 | 사용자 제공, 공급가/부가세 별도 여부 확인 |
| 기본관리비 | 300,000원 | 사용자 제공, 포함 내역·과세 여부 확인 |
| 월 임대료+기본관리비 | 1,000,000원 | 부가세 별도 여부 확인 전 |
| 월별 운영 수업반 | 주 8회 | **모델 예시**(실제 시간표 아님) |
| 1회 정규 요금 | 30,000원 | 기존 공개 사이트 표시가, VAT 포함 소비자가격 가정 |
| 1회 체험 요금 | 25,000원 | 기존 공개 사이트 표시가, 3월 35,000원 변경은 미확정 |
| 한 회차 어린이 | 4명 | 운영상 정원(법정 시설 기준과 별개) |
| 평균 가동률 | 75% | **모델 예시**, 조정 필요 |
| 10주 텀 | 주 1회 x 10주 | 계획, 10주 총액·중도 등록/환불은 미확정 |
| 아이당 수업 재료비 | 3,000원 | **모델 예시**, 실제 지출 아님 |
| 카드/PG 수수료 | 2% | **모델 예시**, 계약 확인 |

실제로 확정되지 않은 비용(대표 보험료, 인건비, 광고비, 전기요금, 인테리어 등)은 기본 0원입니다. **입력값이 0원이라는 이유로 비용이 없다는 뜻은 아닙니다.** 개원 전 견적과 실제 청구서를 대입해야 손익을 과대평가하지 않습니다.

## 2. 과세 처리 — 사용자 지정 비면세 사업

- **일반과세 10% 부가세**를 기본값으로 제공합니다. 면세 교육용역 기본 시나리오를 사용하지 않습니다.
- 수업료 30,000원, 체험료 25,000원은 **부가세 포함 소비자가격**으로 가정합니다. 따라서 30,000원을 결제하면 공급가액 약 27,273원, 매출 부가세 약 2,727원으로 나눕니다.
- 표시가격이 부가세 별도임을 실제 고지한다면 **별도 청구**로 바꾸어 매출액과 세액을 재계산합니다.
- 월세/기본관리비의 부가세 별도 청구 여부는 현재 미확인입니다. 체크박스를 직접 변경한 경우에만 10%를 별도 현금지출·일반과세자 매입세액 공제 *가능성*으로 계산합니다.
- 매입세액 공제는 세금계산서 등의 적격증빙, 사업 관련성, 공제 제한 여부를 확인해야 하며, 모델의 적립액이 실제 납부세액을 보장하지 않습니다.
- 간이과세로 수정하는 경우 부가가치율과 실제 공제·납부면제 기준이 업종 및 사업 조건에 따라 달라집니다. 화면의 간이과세 적립치는 **단순 시나리오**이며 신고 세액 계산기가 아닙니다.
- 직원 급여 원천세는 예수금으로 별도 처리하여 인건비와 다시 더하지 않습니다. 세금 납부 시 실제 거래장에 기록할 수 있습니다.

## 3. 비용 구조

고정 운영비: 월세, 기본관리비, 전기·수도·난방, 인터넷·전화, 출입/보안/CCTV, 청소·방역, 가운 세탁, 폐기물, 시설 보수, 배상책임·화재보험, 세무 기장, 광고, 예약·알림장·클라우드, 문구·인쇄, 렌탈, 그 밖의 고정비.

변동 비용: 식재료·자연소재·소모품(수강 아이와 실제 회차에 따라 증가), 카드/PG 수수료, 결제액 차감·환불률, 체험 참여자 수.

인건비: 실제 직원 월 급여, 사업주 국민연금·건강보험·장기요양·고용보험·산재보험, 퇴직급여 예상 적립, 외주 강사비. **원장의 개인 생활비 인출은 사업 필요경비가 아니라 현금흐름에서만 차감**합니다.

대표자 개인보험료: 국민연금 납부액을 현금흐름·연말 소득공제 추정에 반영하고, 건강보험료는 사업 상황에 따른 비용·현금흐름 추정 항목으로 구분합니다. 실제 소득공제/필요경비 인정은 세무전문가 확인이 필요합니다.

## 4. 2027년 예정 사회보험 기본값

2027년 국민연금 전체 보험료율은 10%, 근로자와 사용자 각각 **5.0%**를 부담합니다. 2027년 건강보험료율은 7.19%로 동결되어 사용자 **3.595%**입니다. 2027년 장기요양보험료는 건강보험료 대비 **13.90%**입니다. 고용보험 사업주 부담률은 기본 **1.15%**를 가정하되, 고용안정·직업능력개발사업 보험료율 및 사업 규모에 따라 달라집니다. 산재보험 **0.72%는 임시 예시**이며 실제 사업장 업종·고시 적용을 확인해야 합니다. 직원 가입 대상·근로시간·고용형태·보수 상하한 등도 반영해야 합니다.

## 5. 손익과 현금흐름의 차이

- **손익**: 제공한 수업 횟수에 맞춰 월 평균 매출을 인식(52주/12개월), VAT 제외 후 원가·운영경비·급여·감가상각 등을 계산.
- **현금**: 실제 결제·세금·보험·대출 원금·사업주 인출·인테리어·보증금 지출 등을 별도 관리.
- 임대보증금은 10,000,000원 현금 유출이지만 반환 예정 자산으로 영업비에 포함하지 않음.
- 인테리어/교구 구입은 개원 시 현금 유출; 자산 계상·감가상각 여부에 따라 월 손익 인식은 달라짐.
- 10주 텀을 미리 결제하는 경우 실제 현금은 먼저 유입되지만 수업을 제공하지 않은 부분을 모두 그달의 매출로 인식하지 않도록 설계.
- 부가세·종합소득세 적립은 실제 납부 전의 현금 준비 추정으로, 거래장에 입력한 세금 실제 지출과 중복 합산하지 않도록 합니다.
- **은행·기존 수납대장·급여관리와 자동 연동하지 않습니다.** 실제 거래는 원장이 입력한 날짜/분류/금액만 집계합니다.

## 6. 손익분기점

수업 1회 아이당 매출(부가세 제외)에서 식재료/소모품/결제 수수료를 차감해 공헌이익을 구합니다. 월 고정비·인건비·감가상각을 공헌이익으로 나누어 월 필요한 아이 참여 횟수와 손익분기 등록률을 계산합니다. 4인 정원은 운영 계획이고 실제 동시 인원과 시설 등록요건 판단은 별도입니다.

## 7. 개인사업자 종합소득세 추정

2026년 누진세율(6~45%)을 적용한 예산 적립 *참고값*이며, 다른 연간 과세소득·소득공제·국민연금 추정을 변수로 반영하고 종합소득세 증가액의 10%를 지방소득세 참고치로 보여줍니다. 손실 이월, 장부 기장, 필요경비/세액공제, 공동사업 여부, 실제 고지·납부액, 2027년 법 개정 및 예정·중간예납은 자동 확정하지 않습니다.

## 8. 비공개 기록·권한

- 별도 메뉴: **스튜디오 관리 → 운영 손익·현금흐름**
- 원장(owner)만 볼 수 있고, **서버도 원장 세션과 finance 권한**을 요구합니다. 선생님·상담 담당자·관리자에게 기본 공개되지 않습니다.
- 계획과 실제 거래는 직원 전용 Google Sheets에 각각 `재무_손익계획`, `재무_현금거래` 탭으로 저장합니다.
- 계획은 수정 버전을 올려 저장, 거래는 이력 보존 방식으로 수정·취소 처리하며 감사기록도 저장.
- 월별 선택/예산 설정/실제 입출금 기록·수정·취소/CSV 다운로드 지원.
- GitHub 정적 JS에 **보증금·월세·관리비 기본 예시 금액이 담겨 있어 공개 소스를 통해 볼 수 있습니다.** 저장된 거래·기타 변경된 사용자 가정은 인증된 GAS·비공개 Sheet에서만 제공합니다. 개인정보나 계좌번호를 메모에 남기지 마세요.
- 원래 수납장부·급여·서명·수업안·공개 상담 페이지는 변경하지 않음.

## 9. 설치와 검증

GitHub 사이트 UI 반영만으로는 서버 권한·저장이 활성화되지 않습니다. 기존 **직원용 Google Apps Script 프로젝트**에 새 `StudioFinance.gs`를 추가하고 최신 `Code.gs`·`StaffBridge.gs`를 반영한 뒤 기존 배포를 새 버전으로 재배포해야 합니다. 수업안 모듈 `LessonPlans.gs`도 패키지에 포함되어 있습니다. 기존 Payroll.gs와 Script Properties, 개인정보 Sheet는 변경하지 않습니다. 별도 초기화 함수를 실행할 필요 없이 첫 저장 시 새 탭을 생성합니다.

CI 테스트: 기본 10% 부가세 포함/별도 시나리오, 임대료/관리비 부가세, 종소세·사회보험, 4인 정원·손익분기, 보증금과 원장 인출 분류, 원장 전용 권한, 이력 저장·중복 요청/변경 충돌, 모바일 UI, 저장 서버 미설치 안내 및 기존 업무 회귀.
