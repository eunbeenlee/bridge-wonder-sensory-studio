# Bridge Wonder V48 — 22개 보호자 Q&A 기반 스튜디오 운영정보 화면

작성일 2026-11-21. 직원용 화면 업데이트만 해당. 공개 홈페이지와 실제 과거 계약·결제·등록 데이터는 변경하지 않습니다.

## 운영안

- 생후 7~48개월, 한 회차 아이 최대 4명, 교사 1명, 50분.
- 현행 모든 클래스는 아이 한 명당 보호자 한 명 동반. 36개월 이후 분리형 수업은 아직 개설하지 않음.
- 정규 수업은 주 1회씩 10주를 한 텀으로 운영할 계획. 주 2회 정규반은 아직 미개설.
- 계절·주간 주제로 매주 다른 재료를 활용. 영어 노래·그림책·감각 탐색을 아이의 속도에 맞춰 진행.
- 재료비 포함 계획. 여벌 옷·앞치마·미술가운 준비 권장. 여분 미술가운 사이즈별 구비 예정.
- 수업 중 아이의 편안함과 즐거움을 최우선으로 운영.

## 기존 계약용 화면과 이번 신규 운영안의 관계

기존 화면에 저장되어 있는 수업비(스크린샷에는 120,000원), 법정 상호, 학원 등록번호, 개인정보 보유 기간, 환불 기준, 결석·보강, 보호자 동반, 재료·안전 안내 및 상태 값은 Google Sheets의 기존 계약용 과정 BW-SENSORY에 연결되어 있습니다. 이 데이터를 자동으로 변경하면 계약서·수업반 기록에도 영향을 줄 수 있으므로 이번 업데이트는 **기존 값을 자동 변경하지 않습니다.**

대신 상단에 운영안 요약과 확인할 사항을 제공하고, 아래 네 필드에만 **운영 문구 초안 선택 적용**을 지원합니다.

1. 보호자 동반 기준
2. 결석·보강 기준
3. 재료·준비물 안내
4. 수업 안전 안내

기존 값이 있으면 덮어쓰기 전에 확인을 요청합니다. '선택한 문구 가져오기'는 브라우저 입력칸만 수정합니다. 사용자가 아래 '기존 수강조건 저장'을 누르기 전까지는 서버에 저장하지 않습니다. 체험 요금, 수업비, 등록번호, 법정 상호, 환불 항목은 자동 변경 대상이 아닙니다.

## 검토가 필요한 기존 답변

- 10주 텀 총액과 선결제, 중도등록, 재료비·부가세, 환불 산식 미확정.
- 체험 요금: 2027년 1~2월 25,000원, 3월부터 35,000원은 운영자 신규안. 기존 홈페이지는 체험 25,000원 및 정규 30,000원 표기.
- 36개월 이상 분리반은 현행 운영에 없음. 새 반을 열 때 법적 운영형태를 다시 검토.
- 당일 결석 보강 불가와 발열 시 대체수업 약속 간 충돌.
- 모든 개인 사유의 환불을 일괄 거절하는 정책은 사용하지 않음. 실제 적용 법령에 따라 취소·환불 규정 확정 필요.
- 안전사고 민형사상 책임을 포괄적으로 면제하는 문구는 사용하지 않음.
- 알레르기 건강정보는 일반 문의나 과정 메모가 아닌 별도 보호 절차로 관리.
- 주차 1시간 기준, 기저귀 교체 공간, 수유 공간, 사진·영상 공유 방식은 현장 및 동의 절차 확인 필요.

법령 근거:

- 학원법 시행령 제18조(적용되는 경우): https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=290261

## 사이트에서 사용하는 방법

직원 사이트 로그인 → 스튜디오 관리 → 스튜디오 운영정보.
상단의 운영 계획을 확인한 뒤 필요한 안내문구 네 가지를 선택하고 '선택한 문구 가져오기'를 누르세요. 입력된 내용을 검토해 적합하면 기존 저장 버튼을 이용하세요. 기존 수업비·상호·등록번호·환불 기준을 임의로 바꾸지 마세요.

이번 변경은 프런트엔드만 수정하므로 Google Apps Script 재설치나 함수 실행은 필요 없습니다. 입력 후 저장에는 기존 서버 함수를 그대로 사용합니다.

## 개발 범위

- 직원 페이지에서만 스크립트 로드. 공개 홈페이지 미변경.
