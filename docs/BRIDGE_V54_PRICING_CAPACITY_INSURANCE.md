# Bridge Wonder V54 — 정규 10주 32만원 · 정원/매출 시뮬레이션 · 보험 UI

## 적용된 운영 기준
- 정규 수업: **주 1회 · 10주 · 총 320,000원** (1회 50분, 환산 32,000원). 체험 25,000원 프로모션은 별도.
- 영유아 반별 최대 정원 4명. 반별 모집정원은 기존 `정원 현황` 화면에서 1–4명으로 변경하고 서버 `staff20SetCapacity`가 실제 확정 인원 초과를 막는다.
- 재무 시뮬레이션은 '스튜디오 상한 4명'과 '한 회 평균 유료 등록 0–4명'을 구분한다. 유료 등록자가 1·2·3명일 수도 있으므로 매출은 실제 예상 등록 인원을 기반으로 산출한다. 이미 납부한 아이의 결석은 자동 환불로 가정하지 않는다.
- 정규 과정 총액과 수업 회차는 UI에서 모두 입력 가능하고, 회당 환산액과 예상 매출이 함께 갱신된다. 기존 V49 서버 스키마의 `regularFee`, `termWeeks`, `occupancy`로만 저장하여 GAS 함수 추가가 필요 없다.
- 기존에 저장된 재무 시나리오가 30,000원이었다면 이를 **임의 덮어쓰지 않는다**. 사용자가 `10주 320,000원 적용` 버튼을 누른 다음 저장할 수 있다.

## 4대보험 표 잘림 해결
- V49 재무 화면의 '직원 사업주 부담 보험·퇴직급여' 8개 금액: 좁은 두 컬럼 레이아웃 제거, 표 최소폭 해제, 표 셀 줄바꿈과 오른쪽 금액 정렬.
- 기존 급여 화면의 연도별 보험요율 카드: 긴 숫자/요율 줄바꿈과 모바일 1열 전환, 테이블의 가로 스크롤 허용.
- 적용되는 보험요율의 법적 정확도는 별도 확인 필요. 이번 변경은 수치 자체가 아니라 표시 영역을 고친다.

## 데이터와 배포
- 기존 Google Apps Script `Code.gs`, `StaffBridge.gs`, `StudioFinance.gs` 및 시트 데이터는 변경하지 않았다.
- 예산 저장은 **기존 V49 재무 서버가 실제 배포되어 있는 경우에만** 작동한다. 서비스 연결이 없으면 계산만 가능하며 저장 버튼은 비활성화된다.
- 수업료 텍스트를 공개 `sensory-studio` 관련 페이지에서도 새 총액으로 업데이트한다. 공개 사이트의 정규 요금은 현재 정적 콘텐츠이므로 직원 UI 수정만으로 공개 페이지까지 즉시 갱신되지는 않는다. 양방향 Google 연동은 사용자가 추후 요청할 때 진행한다.
- 기존 등록계약, 결제내역, 환불 약관, 회계 데이터, 정원 데이터에 일괄 마이그레이션을 수행하지 않는다.
