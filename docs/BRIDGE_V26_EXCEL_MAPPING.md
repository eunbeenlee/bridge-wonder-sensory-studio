# V26 급여 양식 분석과 웹 기능 대응

검토일: 2026-11-20 (대한민국 표준시)

검토 자료: 사용자가 제공한 `예스폼_2025년급여관리프로그램급여계산급여명세서작성4대보험요율자동업데이트.xlsm`.

이 문서는 해당 파일의 시트, 셀 수식, 입력 검증, 이름 정의 및 관계 정보를 읽어 웹 급여관리의 전환 범위를 정리한 문서다. 원본 파일은 수정하지 않았으며 VBA를 실행하지 않았다. 원본의 직원 정보, 급여 내역, 회사 정보, 계좌 정보는 웹사이트 소스나 초기 데이터에 포함하지 않는다.

## 3. 원본의 핵심 계산 구조

원본은 기본급, 수당, 과세·비과세 구분, 개인별 보험 가입 여부, 신고 기준소득·보수, 소득세 및 지방소득세를 결합해 급여를 계산한다. 직원 정보에는 월급·시급·일급과 부양가족, 계좌, 부서·직위 및 입·퇴사 관련 필드가 있다. 시간외근무 시트는 연장·야간·휴일 시간을 집계하며, 급여대장은 이를 지급·공제 계산과 연결한다.

일반 Excel 함수 외에 `CTAX`, `HTAX`, `PTAX`, `INTAX`라는 사용자 정의 함수 호출을 확인했다. 따라서 셀 수식만 옮겨도 원본과 같은 결과가 나온다고 가정할 수 없다. V26은 원본에서 확인한 업무 흐름을 참고하되, 공식 요율과 명시적인 입력값으로 서버 계산을 구성한다.

웹에서 세액을 직접 입력하는 이유는 요율 변경과 세액표 변경의 시점이 서로 다르기 때문이다. 국세청 일반 안내 페이지에는 이전 자녀 공제 사례가 남아 있으나, 국가법령정보센터의 2026년 개정 별표는 다른 공제금액을 제시한다. 원본의 2025년 표나 안내 페이지의 예시를 자동으로 재사용하지 않는다.

## 4. V26에서 유지하는 급여 업무 흐름

1. 원장 계정에서 직원별 급여 정보를 등록한다.
2. 귀속연월과 지급일을 선택하고 급여·근무량·수당을 입력한다.
3. 적용 연도 및 월의 보험 기준과 신고된 기준소득·보수를 확인한다.
4. 공단 고지금액이나 세무 확인 금액이 있는 항목은 해당 금액과 근거를 기록한다.
5. 지급합계, 공제합계와 실지급액을 확인해 초안을 저장한다.
6. 필요한 확인을 마친 내역을 확정하고 급여명세서를 발급·인쇄한다.
7. 실제 이체 후 지급 완료로 기록한다. 정정이 필요하면 사유를 남겨 확정을 취소하고 초안을 다시 작성한다.
8. 연간 집계와 CSV를 이용해 지급 내역을 확인한다.

급여 확정과 은행 이체는 서로 다른 작업이다. 확정 상태나 명세서 발급만으로 실제 지급을 완료한 것으로 간주하지 않는다.

## 5. 원본과 동일하게 제공하지 않는 기능

| 구분 | V26의 범위 |
| --- | --- |
| 원본 VBA 및 사용자 정의 함수 | 실행·복제하지 않는다. 서버 계산을 별도로 구현한다. |
| 예스폼 프로그램의 자동 요율 업데이트 | 해당 제품의 업데이트 기능을 호출하지 않는다. 공식 자료와 적용 기간을 기록해 관리한다. |
| 원본의 모든 항목 설정·표시 옵션 | 사용자 정의 지급·공제 항목은 각각 최대 30개를 지원한다. 통상임금 포함, 합계 제외, 출력 표시 등 원본의 모든 열별 옵션을 동일하게 제공하는 것은 아니다. |
| 소득세 완전 자동 계산 | 가족 수·자녀 수·80/100/120% 및 지급 시점에 따른 전체 간이세액표 엔진을 제공하지 않는다. 확인한 원천징수세액을 입력한다. |
| 사업소득·기타소득·일용근로소득 | 일반 근로자의 월급·시급·일급 계산을 지원한다. 일급제 선택이 세법상 일용근로자 판정을 뜻하지 않는다. 사업소득·기타소득·일용근로소득의 별도 원천징수 체계를 자동 판정하지 않는다. |
| 퇴직금·퇴직소득세·연말정산 | 계산·신고 기능을 포함하지 않는다. 월별 급여관리 기능의 범위를 벗어난다. |
| 근태 자동 연동 | 원본의 일별 근무표나 외부 출퇴근 시스템을 자동으로 읽지 않는다. 확인한 근무량과 수당을 입력한다. |
| 조직도 | 자동 생성 및 조직 편집 기능을 포함하지 않는다. |
| 은행 일괄이체·공단 및 세무 신고 | 직접 실행하지 않는다. 급여 기록·명세서와 구분한다. |
| 사업주 보험료 총비용 예측 | 규모·업종별 고용안정 보험료와 산재보험료를 포함한 사업주 총부담 자동 계산은 제공하지 않는다. |
| 기존 직원·과거 지급 데이터 | 원본 행을 자동으로 가져오지 않는다. 직원 정보를 확인해 등록한다. |

## 6. 공식 기준을 적용할 때의 경계

- 국민연금 요율과 기준소득월액 상·하한은 별도로 관리한다. 상·하한은 7월에 바뀌므로 연도 값 하나로 처리하지 않는다.
- 장기요양보험료는 건강보험료에 적용하는 비율의 계산 방식이 2026년 11월분부터 변경된다. 2026년 1~10월과 11~12월을 구분한다.
- 2027년 건강보험·장기요양 요율의 정부 발표와 2027년 건강보험 상·하한 확인 여부를 구분한다. 확인되지 않은 상·하한을 전년도 값으로 자동 이월하지 않는다.
- 보험 가입, 취득·상실월, 경감·지원, 정산 및 납부예외에 따라 실제 고지금액은 단순 요율 계산과 달라질 수 있다. 확정 시 적용 구분과 실제 고지금액을 확인한다.
- 식대·차량 관련 지급액은 항목명만으로 모두 비과세가 되지 않는다. 요건과 한도, 초과분의 과세 여부를 구분한다.
- 최저임금 검토에는 근무시간과 산입 임금의 범위가 필요하다. 기본급을 일괄적으로 209시간으로 나누는 방식으로 모든 근로계약을 판정하지 않는다.
