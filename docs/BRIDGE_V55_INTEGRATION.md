# Bridge Wonder V55 · 실운영 통합 설치 및 정규 과정 요금 관리

## 새 화면
- /staff/integration/ — 원장 전용 연결 진단·정규 요금 초안 및 공개 승인.
- 기존 직원 로그인 세션 사용. 저장 및 공개는 서버에서 원장 + courseSettings 권한 확인.
- 초기 기준은 10주 320,000원, 주 1회, 50분, 최대 4명. 저장 전에는 기본 계산값일 뿐 서버에 자동 기록되지 않음.
- 초안 시트의 주수·금액을 웹 또는 시트에서 수정할 수 있음. 웹 조회 시 최신 값을 읽고 etag로 저장 충돌을 검사. 수동 시트 변경은 잠금으로 완전히 제어할 수 없으므로 동시 편집을 피할 것.
- 공개 버튼을 눌러 승인한 두 숫자만 별도 Script Property의 공개 스냅샷에 기록. 초안이나 사적 정보는 익명 GET에 노출되지 않음.
- 공개 사이트 홈·프로그램·체험·방문 4곳은 승인된 스냅샷이 있을 때만 업데이트. 서버 미설치/오류 시 기존 10주 32만원 안내를 유지하며 최신 조건은 상담에서 재확인. 향후 가격 변경 후 장애 시 기본 정적 가격과 차이가 날 수 있으므로 공개 페이지 확인 및 필요 시 정적 가격도 갱신해야 함.
- 공개 승인 시 기존 수강계약, 수납, 과거 결제, 재무 예산 가정은 변경하지 않음. 재무 시뮬레이터는 독립 입력값을 유지.

## 설치
1. 현재 직원용 Apps Script 프로젝트(학부모 등록·상담용 프로젝트와 구분)의 파일, Script Properties, 배포 정보, 시트 데이터를 백업.
2. 통합 ZIP의 GoogleAppsScript/ 파일과 기존 코드를 비교. GitHub 버전에 없는 실제 운영 사용자 변경은 보존하고 충돌은 해결한 뒤 교체 또는 추가. 기존 appsscript.json, 배포 실행 주체, /exec URL 및 권한 변경 금지.
3. 원장 Google 계정에서 편집기 함수 setupBridgeWonderV55 실행. 기존 기본 탭 누락/알려진 헤더 불일치가 있으면 생성 전에 중단. 새 콘텐츠·수업안·재무·학사·요금 대장만 추가 생성. 기존 행과 셀은 변경하지 않음. 급여 탭이 누락된 경우 기존 setupBridgeWonderPayrollV26_를 별도 실행(백업 후).
4. 기존 직원 웹앱 수정 → 새 버전 → 배포. 새 URL 생성하지 않음.
5. 직원 사이트 → 연결·요금 관리 → 진단. 연결됐다는 표시는 실제 GAS 응답에 근거. 급여, 등록, 문서 등은 별도 샘플 조회/권한 점검 필요.
6. 요금 초안 10주 320,000원 저장 → 재조회 → 공개 승인. 공개 홈페이지에서 네 페이지를 확인. 실제 결제는 기존 계약 조건 검토 후 별도 처리.

## 보안 및 제한
- 공개 읽기 경로에는 정규 과정 주수와 총액만 포함. 최대 4명과 50분은 현 운영 정책으로 유지. 체험료·할인·세금·환불은 따로 확인.
- 원장만 통합 진단 및 가격 편집 가능. 로그인 없는 호출 또는 일반 직원 호출은 서버에서 거절.
- V51 운영자료/수업안 파일/재무/급여는 기존 RPC와 데이터 대장을 유지. 저장 실패를 성공으로 표시하지 않음.
- 이 설치본은 저장소 기준이며 실제 Google 프로젝트에 자동 설치된 것이 아님. 실운영 데이터의 일치, 실제 배포, 공개 응답은 원장 설치 후 확인.
