# Bridge Wonder V33 — 상단 중심 운영 포털 / 학부모 서류 즉시 발급

## 목적
기존 왼쪽 사이드바(20여 개 업무 버튼)를 화면 중심에서 제거하고, **상단 대분류 → 세부 업무 그룹 → 실행 화면**으로 바로 이동하는 사내 업무 시스템 방식으로 개편합니다.

**이번 변경은 GitHub UI만 우선 적용할 수 있습니다.** 기존 Google Apps Script 로그인·권한·학부모 문서 PDF 발급 API를 그대로 재사용하므로, 학생·직원·급여·시트 데이터 구조를 변경하지 않습니다.

## 업무 분류
| 상단 대분류 | 두 번째 분류 | 이동할 기존 업무 |
|---|---|---|
| 운영 홈 | 공통 업무 | 오늘의 업무 |
| 교육·수업 | 수업 기획 / 학생·출결 / 안전·인계 | 시간표, 월별 주제, 정원, 학생, 출결, 보강, 안전 점검, 인계 |
| 학부모·등록 | 상담 관리 / 수강 등록 / 요청 서류·PDF | 상담, 대기, 등록 확인, 각종 서류 발급 |
| 수납·정산 | 교습비·환불 / 급여 관리 | 수납·환불, 직원 급여 |
| 학원·행정 | 등록·운영 점검 / 교직원 준수사항 | 운영 체크리스트, 법정·행정 관리(서버 V32 배포 시), 학원 기본 정보, 강사 점검 |
| 직원·보안 | 직원·계정 / 접속 기록·백업 | 이메일 계정과 권한, 보안 기록·백업 |

메뉴는 **실제로 해당 계정에 조회 권한이 있을 때만 표시**됩니다. 서버의 기존 권한 검사를 우회하지 않습니다.

## 학부모 서류 발급의 실제 처리 순서
1. 어느 화면에서든 상단 **학부모 서류 PDF** 선택
2. 수강등록 확인서 / 기존 전자서명 계약서 사본 / 납부내역 안내서 / 수업 안내문 / 상담 접수 확인서 / 일반 안내문 중 하나 선택
3. 기존 서버가 제공한 **발급 가능 서류 종류·수강 기록만** 목록에 표시
4. 실제 대상 학생·보호자 기록 선택 → 문서 미리보기 및 수신자 확인 → PDF 생성 → **PDF 내려받기**
5. 기존 발급 기록에서는 재발급 없이 바로 **다운로드** 가능
6. 이메일 발송은 별도 수신자 주소 2회 확인과 개인정보 발송 확인 절차 유지

**수납/납부내역 안내서는 학원법상 교습비 영수증의 대체가 아니며, 서명되지 않은 계약서는 서명 계약서 사본으로 발급하지 않습니다.** PDF 생성·출력 시 Google Apps Script/Drive 서비스가 응답해야 합니다.

## 사용성 개선
- 업무 검색: 상단 `업무 검색` 또는 `Ctrl+K` / `⌘K`. 화면 이동에 서버 호출이 필요하지 않음
- 문서 바로가기: 권한 있는 사용자에게만 표시, 클릭하면 문서 발급 과정으로 이동
- 두 단계 상단 메뉴: 1단계 부서, 2단계 세부 업무. 메뉴를 닫으려면 외부 클릭 또는 Escape
- 운영 화면: 불필요한 왼쪽 여백을 없애고 전체 화면으로 확대
- 반응형: 모바일에서는 상단 분류를 가로로 스크롤하고 세부 메뉴는 세로 리스트로 표시
- 장애 대비: 기업형 메뉴 JS 로딩에 실패하면 기존 왼쪽 메뉴가 유지됨
- 기존 V31 업무 안내, 드롭다운, 직원별 권한, 급여, 법정 문서 생성은 그대로 유지

## 일괄 적용과 주의
- GitHub Pages의 `/staff/` 관리자 화면은 PR 병합 후 새로운 상단 메뉴가 적용됩니다. 로컬 캐시를 제거하기 위해 `administration.js` 등 프런트엔드 에셋의 버전을 `33.0.0`으로 올렸습니다.
- 직원용 Google Apps Script의 직접 `/exec` 주소로 접속하는 경우 최신 `Admin.html` 화면을 쓰려면 **그 파일만 교체하고 기존 배포를 새 버전으로 배포**해야 합니다. 백엔드 `Code.gs`/Script Properties/시트 수정은 V33만을 위해 필요하지 않습니다.
- GitHub UI 변경으로 8초 로그인 시간이 자동으로 1초가 되는 것은 아닙니다. 이번 변경은 화면 구성/이동의 체감 편의성에 초점이 있습니다.
- 개발·자동 테스트는 기존 서버 데이터·실제 학부모 계약서를 읽거나 쓰지 않습니다.

## 테스트
- `npm run check`: 경로·HTML·JavaScript·생성 레이아웃
- `npm test`: V30/31 회귀 + V33 상단 메뉴·권한 분리·PDF 빠른 선택 테스트
- 실제 학부모 PDF의 원본 데이터 적합성, 브라우저 다운로드, 저장된 PDF 품질은 운영 계정에서 수신자/발급 대상을 확인하여 별도 점검합니다.

## V32 법정 점검 시스템과의 관계
법정·행정 관리 모듈은 별도 PR에서 작업되며 Google Apps Script 추가 서버 파일(`Compliance.gs`, `InspectionPDF.gs`)이 필요합니다. V33 상단 메뉴는 해당 PR이 적용되면 해당 권한 메뉴를 자동으로 포함합니다.
