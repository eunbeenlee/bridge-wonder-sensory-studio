# Bridge Wonder V41 — 직원 사이트 상단 메뉴·4색 톤앤매너·자연스러운 한국어

## 대상 및 적용 원칙
- **대상:** `/staff/` 직원 사이트와 `/staff/standalone.html` 보조 접속 화면
- **변경하지 않음:** `/sensory-studio/` 공개 홈페이지, 메인 사이트, Google Apps Script 서버 파일/배포, Google Sheets, 기존 학생·보호자·급여·수납 자료
- **기존 기능 유지:** 역할별 메뉴 권한, 로그인·OTP·비밀번호 초기 설정, 문서 발급, 수업 시간표, 출결, 보강, 급여, 등록 원본
- 운영 시스템은 기존 Google Apps Script 서비스를 이용합니다. 표시 문구에서 외부 공급자 이름만 제거하며 실제 호스팅이나 인증 구조를 자체 서버로 이전하지는 않습니다.

## 네 가지 브랜드 색상
공식 Sensory Play Studio `assets/css/site.css` 기준:
- **Forest Green `#40543A`**: 글 제목, 선택된 메뉴, 주요 버튼
- **Sage `#99A682`**: 부드러운 구분선, 포커스 효과, 상태 강조
- **Cream `#FBF8F2`**: 전체 배경, 로그인 배경과 콘텐츠의 온화한 바탕
- **Terracotta `#D1693B`**: 주의사항·현재 선택 강조 등 필요한 부분에만 소량 사용

흰색과 중립 회색은 가독성 확보용 표면과 본문 글자에만 사용합니다.

## 레이아웃
- **데스크톱:** 왼쪽 고정 사이드바를 숨기고 상단 카테고리 5개 + 스튜디오 홈 + 메뉴 찾기 + 서류 발급
- **모바일:** 상단 카테고리는 스크롤 가능한 한 줄, 홈·검색·서류 버튼은 충분한 터치 영역 유지
- **업무 홈:** 운영 현황은 하나의 KPI 영역, 업무 목록은 중첩된 카드를 줄이고 얇은 구분선으로 구성
- **상세 화면:** 기존 기능을 건드리지 않고 테이블, 폼, 메시지·상태 색상과 여백 정리
- **로그인:** 이전 V40 2열 브랜드 레이아웃 유지, 네 가지 색 적용. 영문 장식·‘Google 서버’ 안내 제거. 연결 상태·접속 도움말로 바꾸고 별도 접속 링크는 접힌 도움말에 보존

## 문구 교정 예시
- '학생 초안으로 옮기기' → **'아이 정보로 가져오기'**
- '진행 상태 업데이트' → **'상태 바꾸기'**
- 'Google 관리 서버 업데이트 필요' → **'관리 시스템 업데이트가 필요합니다'**
- '관리자 직접 등록 학생' → **'직접 등록한 아이'**
- '수업 준비·안전' → **'재료·안전 점검'**

이용약관·계약 원본의 법률상 명칭과 서버의 상태값은 임의로 바꾸지 않았습니다.

## 기술·테스트
- V40 마지막 CSS에 V41 스타일을 추가해 **불필요한 CSS 파일 요청을 늘리지 않음**
- 직원 웹페이지와 변경된 JS에 `?v=41.0.0` 적용, `package.json` 버전 동기화
- 기존 **총 회귀 테스트**와 신규 `tests/staff-topnav-v41.test.cjs`를 GitHub Actions로 수행
- 상단 5개 카테고리 클릭/검색, 역할별 보임, 로그인 입력 필드/보조 경로 유지, 스튜디오 4색 및 공개 사이트 불변 검증
- 새로운 Apps Script 함수 실행이나 재배포는 필요하지 않음

## 실제 운영 확인
로그인 후 화면 데이터 및 권한은 원래 운영 서버가 제공합니다. 브라우저에서 확인할 때는 로그인, 상단 메뉴, 월간 테마, 학생 기본정보, 출결, PDF, 급여로 이동되는지 확인해 주세요. Google 직원 웹앱 자체에 배포되어 있지 않은 V38 서버 기능은 이 UI 개편으로 새로 활성화되지 않습니다.
