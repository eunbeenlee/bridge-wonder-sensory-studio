# Bridge Wonder V39 — 센서리 스튜디오 직원 운영화면 중심 개편

## 적용 범위
**GitHub 직원 사이트 `/staff/` 화면 전용.** 브릿지 원더 메인 홈페이지 및 모든 `/sensory-studio/` 공개 페이지, Google Apps Script의 `Code.gs`·`Payroll.gs`·`StaffBridge.gs`, 데이터 시트, 비밀번호, 학부모 개인정보 및 기존 수강계약 PDF는 수정하지 않습니다.

## 운영 흐름에 맞게 재배치
- **상담·등록:** 체험·클래스 상담, 대기·일정 협의, 아이 기본정보, 등록 서류 확인
- **클래스 운영:** 시간표·정원, 아이 명단, 출결·보강, 보호자 인계
- **오감놀이 준비:** 월간 체험 테마, 월간 오감놀이 계획, 재료·안전 점검
- **이용료·문서:** 수업비 수납·환불, 보호자 문서·PDF
- **스튜디오 관리:** 시설·운영 점검, 실제 적용 기준 확인, 직원·급여·보안

기존 메뉴 ID와 RPC 권한은 그대로 보존합니다. 새 업무 API나 Google 호출을 만들지 않습니다.

## 홈과 모바일 화면
- 원장·관리자·선생님·상담 담당자에게 **허용된 업무만** 첫 화면에 4개 업무 그룹으로 보여줍니다.
- 기존 수업반·상담·등록 현황은 서버가 실시간으로 알려준 실제 수치만 표시합니다.
- 2열 카드 배치, 태블릿 1열, 매우 좁은 휴대폰 화면에는 버튼을 세로로 배열합니다.
- 프로그램 내용과 법정 계약 서류를 새 사업 유형에 맞는 것으로 자동 변환하거나 삭제하지 않습니다.

## 법적 구분
화면은 **센서리 스튜디오·감각놀이 체험·교육서비스 운영**에 맞춘 내부 업무 편의 개선입니다. 이것만으로 사업자등록 업종이 ‘교육서비스지원업’으로 변경되거나 학원법·안전·개인정보 관련 의무가 면제되는 것은 아닙니다. 실제 등록 업태·종목, 교습 형태, 시설 인허가와 관할기관 판단을 별도로 확인해야 합니다. 기존 법정 점검 항목·신고정보·계약 조건·정규 50분 30,000원/체험 50분 25,000원 안내는 유지합니다.

## 배포
GitHub Pages의 `/staff/` 화면은 V39 브랜치 병합 후 반영됩니다.
Google Apps Script `/exec` 직접 접속 화면은 V38 그대로 유지합니다. 휴대폰에서는 Google 프로젝트를 수정할 필요가 없습니다. 나중에 Google 업데이트를 진행할 때는 해당 프로젝트용 `Admin.html` 스타일 및 프런트엔드 버전도 V39에 맞춰 검토할 수 있습니다.
