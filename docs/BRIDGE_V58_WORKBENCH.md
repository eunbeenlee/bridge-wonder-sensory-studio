# Bridge Wonder V58 · 오늘의 업무 허브 및 전체 업무 연결

## 새로운 화면
- /staff/workbench/ : 직원 권한에 따른 상담·등록 상태·대기·보강·반 정원 설정·오늘의 안전점검·개원 운영점검·요금 공개 승인·손익계획 저장 상태 집계.
- 개원·운영 점검은 기존 운영 체크리스트의 완료 기록과 날짜를 집계하며, 인허가나 안전 적합성 판정으로 사용하지 않는다.
- 기한 경과 및 다음 7일의 항목은 최대 8개 표시. 직접 입력한 담당자, 증빙, 메모, 아동·보호자 개인정보는 반환하지 않는다.
- 정원 요약은 등록된 반의 1~4명 모집 정원 설정 여부 및 중복·잘못된 설정 확인. 실제 등록 인원이나 수납액은 기존 정원·재무 화면에서 확인.
- 등록 확정 외 기록에는 취소 기록도 포함될 수 있다. 안전점검 수치는 당일 작성 기록만 집계하며 예정 수업 전체에 대한 점검 완료 여부를 뜻하지 않는다.
- 원장/관리자/선생님/상담 담당자의 실제 서버 조회 권한에 따라 표시. 선생님 반별 업무는 담당 반만 집계.
- 각 업무는 기존 화면에서 수정. 별도 중복 업무 시트는 만들지 않는다.
- 대장 누락, 열 구조 오류, 5,000행 초과, 개별 읽기 실패는 0이 아닌 별도 상태 표시. 조회 시 기존 데이터를 만들거나 수정하지 않는다.
- 1회 인증 후 통합 조회 요청. 수동 재조회 시 세션·권한 확인. 업무 검색은 현재 권한 메뉴만 브라우저에서 검색하며 네트워크 호출이 없다.
- 직원 메인과 독립 관리 8개 화면의 공통 업무 메뉴 보강. 기존 V57 미저장 입력 보호 및 모바일 레이아웃 유지.

## 설치 안내
Google 실서버 미적용 상태에서는 기존 업무 바로가기·검색은 사용할 수 있지만 V58 실제 대장 집계는 표시되지 않는다.
V57 이전이라면 이번 통합 ZIP의 13개 직원 전용 Apps Script 소스 파일을 백업·비교한 후 기존 Staff 프로젝트에 반영한다. 공개 상담/등록 프로젝트에는 설치하지 않는다.
V57까지 설치했다면 StaffBridge.gs 변경분을 적용하고 StudioWorkbenchV58.gs 추가. V58 자체 신규 시트나 초기화 함수는 필요 없다.
V55 이후 통합 초기화가 필요할 때만 원장 계정의 편집기에서 setupBridgeWonderV55 실행. 기존 /exec 주소 및 실행 주체 유지, 배포 관리에서 기존 웹앱의 새 버전을 배포한다.
실데이터 조회와 모바일 실사용은 설치 후 직접 확인. GitHub 자동 테스트는 가상 데이터·모의 시트와 DOM 기반이다.
