## 구성

A 등록·프로그램 안내 5문항, B 수업 내용·교육 방향 5문항, C 아이 적응·수업 환경 5문항, D 환불·안전·시설 이용 5문항, E 운영 원칙·기타 2문항을 반영했습니다.

각 질문에 운영자가 작성한 원문, 직원이 참고할 자연스러운 답변 초안, 확인 상태, 확인해야 할 운영 메모를 함께 넣었습니다. 검색·분야 필터·상태 필터·질문별 펼침이 가능하며, 검토가 필요한 답변은 복사 버튼이 없습니다.

## 실제 사용

1. 직원 사이트 로그인 → 상담·등록 → 체험·클래스 상담
2. ‘보호자 예상 질문·응대 가이드 22문항’을 펼쳐 검색
3. 응대 초안은 필요한 경우 복사; ‘확인 필요’·‘내부 메모’는 복사 기능 비활성화
4. 원문은 각 질문의 ‘운영자 작성 원문 보기 (검토용)’에서 확인
5. 정책을 확정한 뒤 별도 요청으로 공개 홈페이지에 선별 반영

## 저장과 공개 범위

이번 작업은 직원 사이트 화면에만 추가하는 읽기 전용 기능입니다. **Google Apps Script 재설치·함수 실행 없음.** 기존 상담·급여·문서·등록 자료에 손대지 않습니다. 직원이 답변을 직접 편집·저장하는 기능은 아직 없습니다.

**중요한 한계:** FAQ 원문과 초안은 GitHub Pages가 내려주는 JS 파일에 포함되므로, GitHub 저장소가 공개라면 소스 URL을 통해 내용을 열람할 수 있습니다. 일반 홈페이지에는 표시되지 않지만 **기밀성은 보장되지 않습니다.** 진정한 비공개 자료로 운영하려면 이후 인증된 서버에서 데이터를 제공하도록 변경해야 합니다. 이번 내용에는 실제 아동·보호자 개인정보를 포함하지 않았습니다.
