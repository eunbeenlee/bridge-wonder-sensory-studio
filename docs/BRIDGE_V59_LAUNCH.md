# Bridge Wonder V59 · 개원·교육·홍보 계획

## 이전 작업에서 통합한 기준
- 사용자 운영 기준: 7~48개월(0~6개월 제외), 50분, 주 1회 10주 320,000원, 반당 최대 4명, 전 연령 보호자 1명 필수 동반, 2027년 1월 오픈 예정.
- 기존 B안 통합운영 V3의 12개월 테마, 48회 슬롯, 1·3회 식재료/2·4회 자연소재, 5개 월령반, 배정량·교사 시범분·손실율·구매단위·준비/정리시간을 참고 템플릿으로 반영. 원본 워크북/교재/사진은 공개 저장소에 복제하지 않는다.
- 원본의 보호자 동반 예외는 최신 동반 필수 기준으로 대체. 홍보물의 0~48개월 표기는 수정 검토 항목. 현장 인쇄물은 직접 교체 필요.
- 월령별 반 수와 반당 0~4명 인원 조절, 식재료 kg당 단가 입력 시 발주량과 원가 산출. 7~24개월 직접 배정 0g, 25~48개월도 개별 안전 승인 후 비섭취 활동만. 월 1·3회 별도 신선분 구매, 아동 접촉물 재사용 금지. 실제 발주·재고 차감·공급처 발송은 수행하지 않는다.
- 36~48개월 IBL + Art 연계는 실제 Art 교재의 목차·페이지 확인이 남은 상태. 3개월 12회 준비 및 첫 4회 시연을 검토 지표로 사용.
- 시설: A/B 공간 및 가벽, 기존 수도·전기/온수, 단열/전기판넬, 시트지와 색상 검수. 공사 전후관계는 검토 항목으로 관리하며 설비 적합성을 판정하지 않는다.
- 안전/보험: 사업 분류 미확정, 관할 확인. 보호자 동의서 6종 검토(등록, 약관·환불, 동반 안전, 민감정보, 개인정보·촬영, 응급/서명). 서명으로 법적 책임 면제 불가, 선택 촬영 동의 거부 불이익 금지. 실제 문서 발급/수집 기능은 기존 문서 체계에 연결하지 않고 별도 검토.
- 홍보: 과거 20개 검토 채널에 아파트너·아파트리·아파트아이 세부 항목 추가. 예산·실제 비용·문의/체험/유료 등록 수치 미입력. 상위 입주민 앱 채널과 개별 앱의 비용 및 실적 중복 입력 금지. 범위 부산 전역·양산 및 인접 지역.
- 미확정 금액, 가입 여부, 실제 공사 완료를 임의로 채우지 않음. 현재 원본 이외의 전체 자료를 모두 확보·검증했다는 의미는 아니다.

## 사용 및 저장
/staff/launch/ 원장 전용. 기존 운영 권한 확인, 저장은 별도 BW59_개원교육홍보계획 개정 이력 탭으로 추가. 한 개 연간 계획을 수정하는 형태(기본 2027). 이전 계획 행 보존. 동일 요청 중복과 최신 etag 확인. 원본 재무/계약/공개 홈페이지 미변경. CSV 내보내기 제공. 기본 템플릿은 공개 JS 자산에 있으므로 실제 단가·업체·담당자·개인정보는 포함하지 않는다.

## 설치
기존 Staff Apps Script 프로젝트만 대상. V58 이후에는 StaffBridge.gs, StudioIntegrationV55.gs 변경 및 StudioLaunchV59.gs 추가. 이전 서버이면 V59 통합 ZIP 14개 소스를 백업·비교 후 적용하고 원장 계정으로 setupBridgeWonderV55 실행(새 계획 탭 생성), 기존 웹앱 새 버전 배포. /exec 주소 유지. 실제 Google 데이터 및 공개 등록 프로젝트는 GitHub 배포로 변경되지 않는다.
