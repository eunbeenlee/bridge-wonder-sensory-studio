# Bridge Wonder V45 — 보호자 참여형 4명 수업 + 직원 수업안 자료실

## 이번 버전 운영 기준

- **대상:** 생후 7~48개월
- **한 회차:** 아이 최대 4명. 아이 1명당 보호자 1명이 50분간 함께 참여
- **분리 돌봄·아이 단독 이용:** 운영하지 않음
- **공개 사이트:** 홈·프로그램·체험 테마·방문/문의·브랜드 이야기의 안내 문구와 예약 흐름에 반영
- **가격 안내 유지:** 정규 50분 30,000원 / 체험 50분 25,000원, 실제 결제·세금·환불 조건 확인 필요

### 공개 온라인 수강 등록 유의사항

기존 `/sensory-studio/enroll/`은 학원형 수강계약·전자서명 서식과 연결되어 있어, 신설 스튜디오의 계약과 혼용되지 않도록 **신규 등록 입력을 일시 중단**했습니다. 해당 페이지는 상담 안내로 연결됩니다. 기존 등록 데이터와 전자서명 파일, 비공개 Google Sheets, 기존 수납내역은 삭제하지 않았습니다. 기존 등록 클라이언트 소스와 그 회귀 테스트용 HTML은 유지합니다.

신규 이용 신청서·환불조건·사진·영상 동의서는 법적 검토 후 별도 기능으로 연결해야 합니다. 이 버전에서 아직 발급 가능하다고 표시하지 않습니다.

## 수업안 자료실

**직원 사이트 → 오감놀이 준비 → 월간 오감놀이 계획 → 수업안 자료실**

수업안을 어떤 형식으로 작성할지 아직 정하지 않아도 됩니다. **고정 입력 양식은 없습니다.** 원래 만든 문서를 그대로 올리고 간단한 관리 정보만 붙여 사용합니다.

- 지원 파일: PDF, DOCX/DOC, PPTX/PPT, XLSX/XLS, HWP/HWPX, TXT, JPG/JPEG, PNG, WEBP
- 최대 크기: 파일당 **8MB**. 큰 파일은 줄이거나 PDF로 내보낸 뒤 업로드
- 입력: 파일 선택, 제목(필수), 적용 월(선택), 월령(전체 / 7~12 / 13~18 / 19~24 / 25~35 / 36~48), 메모(선택)
- 업로드: 작은 단위로 나누어 전송. 진행률 표시·중단·미완료 업로드 정리 지원
- 목록: 검색·월령·공유상태 필터, 파일 다운로드
- 관리: 제목·적용 월·월령·메모 수정, 선생님 공유/비공개 전환, 보관처리(원본 삭제 아님)
- **권한:** 원장·관리자는 업로드·관리. 선생님은 ‘공유’ 상태만 조회·다운로드. 상담 담당자는 자료실 파일을 조회하지 못함
- **보관:** 기존 직원용 Apps Script를 통한 비공개 Google Drive 폴더 `BridgeWonder_수업안_비공개` + 별도 비공개 Sheets 색인 `운영_수업안자료`
- **민감정보:** 아이 이름/사진·연락처·건강정보 등은 수업안에 포함하지 않습니다. 외부 문서는 바이러스 확인 후 열어야 합니다. 공개 Drive 링크는 생성하지 않습니다.

## 신규 관리 기능을 사용하려면: Google 직원 서버 설치 필요

GitHub Pages는 파일을 직접 안전하게 저장할 수 없습니다. 이번 수업안 업로드는 **기존 직원용 Google Apps Script** 저장 모듈을 호출합니다.

1. 기존 **직원용 Apps Script 프로젝트**를 백업합니다. 학부모 상담·등록 전용 별도 프로젝트에 설치하지 마세요.
2. 설치 패키지 `Bridge_Wonder_V45_Staff_AppsScript_Install.zip`에서 기존 파일(특히 `Code.gs`, `StaffBridge.gs`)은 같은 이름의 파일로 업데이트합니다.
3. **`LessonPlans.gs`를 새 Apps Script 파일로 추가**합니다. 다른 서버 파일은 이미 설치한 버전에 맞춰 교체·확인하고, 기존 `Payroll.gs`와 데이터 시트는 그대로 둡니다.
4. **배포 → 배포 관리 → 기존 웹앱 수정 → 새 버전 배포**를 진행합니다. 현재 직원용 `/exec` 주소를 유지하며 실행 주체·접근 설정을 임의 변경하지 않습니다.
5. 원장 계정으로 직원 사이트 로그인 → 월간 오감놀이 계획 → 수업안 자료실을 열어 소형 가상 PDF 파일을 업로드하고 다운로드합니다. 선생님 계정에서 **공유된 자료만** 보이는지 확인합니다.
6. 첫 사용 시 Apps Script의 Drive 접근 권한 승인이 필요할 수 있습니다. 이는 실제 구글 계정에서 직접 확인해야 합니다. 별도 설치 함수를 실행하거나 기존 데이터 초기화를 진행할 필요는 없습니다.

**서버가 설치되지 않은 경우:** 직원 페이지에 '수업안 자료실' UI와 **관리 서버 업데이트가 필요하다**는 메시지가 표시되며 실제 업로드는 비활성화됩니다. 기존 수업·문서 관리 기능은 계속 유지됩니다.

## 사용 전 확인
- 개인정보, 특히 아동의 이름·건강정보가 포함된 파일을 업로드하지 않도록 직원 교육
- 법정 학원·교습소 해당 여부는 공식 판단 확보 전까지 '비대상 확정'으로 표시하지 않음
- 소규모 대면교습 관련 법제처 **2026-01-28, 25-0736** 해석은 참고자료. 교습소 규제, 보호자의 학습자 수 산정, 실제 시설 동시 인원, 사업자등록 업종 및 건축·소방 기준은 별도 확인
- 정원 4명은 **한 회차에 참여하는 아이 수**. 보호자와 직원 등을 포함한 실내 안전 수용 인원과 다른 공간의 동시 운영 여부는 별도 점검
