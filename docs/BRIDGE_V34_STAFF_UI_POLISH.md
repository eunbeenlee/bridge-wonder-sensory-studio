# Bridge Wonder V34 | 관리자 화면 이미지·문구 마감

## 변경 목적
V33 상단 업무 메뉴를 그대로 유지하면서 화면이 좁을 때 로고·제목·버튼과 상단 메뉴가 겹칠 수 있는 구조를 수정하고, 직원에게 보이는 짧은 안내 문구를 실제 업무 순서에 맞게 정리했습니다. **기능·권한·데이터·시트·Google Apps Script API는 변경하지 않습니다.**

## 시각적 개선
- 기존 상단 제목 영역과 메뉴를 각각 고정시키면서 기기의 줄바꿈 높이를 반영하지 못하던 구조를 해소했습니다. **상단 브랜드 영역은 일반 문서 흐름**, 업무 메뉴만 스크롤 시 상단에 남습니다.
- 데스크톱은 로고·현재 업무명과 계정/로그아웃 버튼을 서로 다른 그리드 영역에 표시하고, 좁은 화면에서는 두 줄로 정리합니다.
- 로고의 가로·세로 크기를 제한하고 원본 비율을 유지합니다. 문서 미리보기 로고도 본문·표와 겹치지 않도록 별도 행에 배치합니다.
- 5개 업무 대분류가 넓이를 초과하면 메뉴 줄에서 가로 스크롤됩니다. 열려 있는 세부 메뉴는 화면 너비를 넘지 않도록 제한합니다.
- 설명 문구는 지나치게 작거나 흐리지 않도록 글자 크기·행간·명도를 조정했습니다.

## 문구 개선
- 수업반: 시간/요일/과정 선택과 공개 상태를 짧고 직접적인 표현으로 안내
- 수강생·출결·보호자 인계: 교사가 실제로 확인할 내용 중심으로 작성
- 교직원·점검: 기술 용어 대신 담당자·기한·증빙 확인 안내
- 수납·환불·급여: 실제 처리 결과를 확인하고 기록하도록 명확히 안내
- 문서 발급: PDF 선택·미리보기·발급·다운로드·메일 발송 순서로 표현 정리
- 로그인·임시 비밀번호: 스프레드시트·웹 서비스 이름을 나열하던 설명 대신 직원이 무엇을 해야 하는지 안내

**유지한 중요 내용:** 전자서명 계약서 원본과 등록 확인서 구분, 납부내역 안내서와 법정 영수증 구분, 개인정보 보호, 직원 권한, 배상책임·기한 점검 안내.

## 변경 범위
- `assets/css/staff-polish-v34.css` **신규** (기존 디자인/CSS 변경 없음)
- `assets/js/administration.js` / `assets/js/administration-payroll.js` 사용자 안내 문구 정리
- `assets/js/staff-ux-v31.js` 각 화면의 사용법을 자연스러운 한국어로 통일
- `assets/js/staff-enterprise-v33.js` 상단 PDF 바로가기·서류 종류의 보조 설명 수정
- `assets/js/staff-account-management.js` 임시 비밀번호 발급 설명 수정
- `staff/index.html`, `staff/standalone.html`, `staff/administration.html` 로그인 안내 조정
- `assets/js/administration-layout.js` / `tools/build-administration.py` 생성 스크립트 동기화
- 버전 `34.0.0` 적용: 브라우저에 이전 JavaScript가 남지 않도록 로딩 주소 버전 갱신
- V34 정적/행동 회귀 테스트 추가

## 배포
GitHub Pages `/staff/`에서는 PR 병합 후 변경된 UI가 반영됩니다. Google Apps Script의 공식 직접 접속 `/exec` 화면은 새 `server/apps-script/Admin.html`을 기존 직원용 프로젝트에 적용하고 **기존 웹앱을 새 버전으로 배포**하면 동일한 스타일이 적용됩니다.

**별도로 교체하지 않는 파일**: `Code.gs`, `StaffBridge.gs`, `Payroll.gs`, 스프레드시트 데이터와 Script Properties.

## 검증
`npm run check`, `npm test`의 기존 테스트와 `tests/staff-polish-v34.test.cjs`를 실행합니다. 실제 데스크톱/모바일 브라우저에서 각 화면의 픽셀 충돌과 PDF 원본 품질은 배포 후 확인이 필요합니다.
