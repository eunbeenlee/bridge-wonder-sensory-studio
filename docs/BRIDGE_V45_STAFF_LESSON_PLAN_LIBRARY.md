# Bridge Wonder V45 — 직원용 수업안 파일 자료실

## 목적
수업안 파일의 **정해진 양식이 없더라도** 직접 업로드·검색·다운로드·수정본 관리할 수 있도록 하는 직원 전용 기능.  
기존 **월간 오감놀이 계획**과 별개로 관리되며 기존 테마·보호자 안내·계약 정보를 변경하지 않습니다.

## 접근 경로
1. `https://bridgewonder.bridgeacademy.co.kr/staff/` 원장 로그인
2. 직원 홈의 **수업안 파일 관리**, 또는 상단 **오감놀이 준비 → 월간 오감놀이 계획**
3. 화면 상단 **수업안 파일**에서 업로드·목록 확인

## 파일 및 입력
- 형식: PDF, DOCX, XLSX, PPTX, HWP, HWPX, PNG/JPG, TXT, CSV
- 최대 용량: **파일당 5MB**
- 반드시 필요한 값: 파일 1개
- 선택 입력: 수업안 제목(비우면 파일명), 적용 월, 대상 월령, 관리 메모
- 월령 선택: 전체(7~48개월), 7~12, 13~18, 19~24, 25~35, 36~48개월
- 고정 양식 없이 파일 자체를 보관. 편집 가능한 온라인 수업안 작성기는 아직 추가하지 않았습니다.

## 관리 기능
- **새 파일 등록:** 업로드 진행률 표시, 완료되면 자료실 목록에 반영
- **수정본 등록:** 같은 수업안에 버전 번호를 하나씩 추가하며 이전 파일을 보관
- **이전 버전 다운로드:** 원하는 버전을 직접 선택
- **정보 수정:** 파일을 바꾸지 않고 제목·월·월령·메모 수정
- **보관 / 다시 사용:** 파일은 삭제하지 않고 수업안 목록에서 분리
- **목록 검색:** 제목·파일명·월령·메모
- Google Drive에 외부 공유 링크를 만들지 않으며 로그인 및 서버 권한을 확인한 뒤 파일 바이트를 전달합니다.

## 역할·보안
- 원장·관리자: 자료실 보기, 업로드, 수정, 보관/복구, 다운로드 (기존 '월간 놀이 계획' 쓰기 권한이 허용되어야 함)
- 선생님: 사용 중인 자료실 보기 및 다운로드 (기존 '월간 놀이 계획' 읽기 권한 필요)
- 상담 담당자: 파일 자료실 열람 권한 없음
- 직원에게 수업안 파일의 Drive 원본 ID나 직접 공유 주소를 노출하지 않음
- 승인되지 않은 HTML/실행파일 확장자를 차단하고 PDF/이미지/한글/압축형 Office 파일은 서버에서 기본 파일 시그니처를 확인
- 파일 바이너리 SHA-256 무결성 확인 후 다운로드
- 아이 이름, 보호자 전화번호, 건강정보, 개인정보가 있는 자료는 업로드하지 않도록 안내
- 업로드/수정/보관/다운로드 기록은 기존 직원 감사 기록으로 남김
- 원본 파일은 직원용 Apps Script 실행 주체의 비공개 Drive 폴더에 저장

## 서버 작업 — 필수
V43~44는 화면 기능 변경만으로 적용되었지만, **V45는 서버 저장 기능이 추가되어 기존 직원용 Apps Script 배포 업데이트가 필요**합니다.

전용 설치 ZIP: `Bridge_Wonder_V45_Lesson_Plans_Staff_Update.zip`

순서:
1. 기존 직원용 Apps Script 프로젝트 및 배포를 백업
2. 새 `LessonPlans.gs` 파일 추가
3. 기존 `StaffBridge.gs` 파일을 V45 전체 내용으로 교체
4. 배포 관리에서 **기존 직원 웹앱**의 새 버전으로 업데이트 (기존 `/exec` 유지)
5. 사이트 새로고침 후 허구의 PDF로 업로드·수정본·다운로드 테스트

**별도 설치 함수를 실행할 필요 없습니다.** 새 Google Sheets 탭과 비공개 Drive 폴더는 첫 업로드 때 자동 생성합니다. 단, 실행 주체의 Google Drive·Sheets 권한은 유지돼야 합니다.

**주의:** 공개용 상담/등록 Apps Script 프로젝트에는 절대 설치하지 마세요.  
기존 `Code.gs`, `Payroll.gs`, `AcademicManagement.gs`, `Compliance.gs`, `InspectionPDF.gs`, `Admin.html`, Script Properties, 개인 정보 기록은 변경하지 않습니다.

## 업로드 통신 구조
기존 Google Apps Script HTTP bridge의 350,000자 요청 제한을 그대로 두고,
약 **180KB(파일 바이트)씩 순차 업로드**합니다. 요청이 중복 전송되면 같은 조각은 중복 저장하지 않습니다.
업로드가 끝나고 파일 무결성이 확인된 후에만 자료실의 사용 중 목록에 나타납니다.

업로드 도중 브라우저를 닫으면 진행 중 파일은 임시 폴더에 남을 수 있습니다. 현재 V45에서는 브라우저를 다시 열었을 때 이어 올리기가 지원되지 않으므로 같은 파일을 다시 선택해 업로드해야 합니다. 업로드 중에는 화면을 닫지 않는 것이 좋습니다. 추후 오래된 임시파일 정리·재개 기능을 추가할 수 있습니다.

## 검증 범위
- Node 합성 데이터: 서버 role 권한·파일명/용량 검사·청크 재전송·버전 기록·보관/복구·SHA 무결성·문서 위장 검사
- JSDOM: 폼 업로드, 서버 미설치 안내, 월간 계획 유지, 브라우저 상태 안전성
- 기존 V44 포함 프로젝트 회귀 테스트 및 정적 HTML/JS 문법검사
- 실서비스 Drive 폴더 권한·업로드 속도·Google 웹앱 호출은 서버 배포 후 가상 자료로 확인 필요

## 공개 페이지 변경 없음
공개 `/sensory-studio/` 및 하위 상담·방문·체험·등록·개인정보 화면, 기존 보호자 문구, 가격표, 이메일·전자서명 기록 등은 V45 변경 대상이 아닙니다.
