# Bridge Wonder V56 · 반별 손익·수납·운영계획

## 새 화면: /staff/planning/
정규 과정 기본값 10주 320,000원, 최대 4명. 시작일별 반을 나누고 0~4명 유료 등록 인원, 반 수, 모집 정원을 따로 지정합니다. 기본 8개 반에 3명씩은 기존 재무 예산의 예시이며 실제 등록 기록이 아닙니다.

- 과정 시작일, 주수, 총액, 월별 예측 기간(1~18개월), 수납 방식, 재료 원가, 고정비, 보험·급여 등이 포함된 기존 예산 합계, VAT·수수료·할인·환불 가정, 시작 현금 잔액을 조절.
- 0명 등록 반은 수업 미운영, 고정비는 계속 발생. 재료 목록은 아이 한 명의 1회 사용량을 기준으로 계산. 박스/팩 등 등록 단위와 실제 사용량을 일치시키고 기타 재료비와 중복하지 않음.
- 월별 실제 날짜 기준 수업 배분. 매주 1회, 휴강 미반영. 선결제는 첫 수업일에 전체 수납, 주차별 분할은 매 수업일 수납 가정. 분할 금액은 정수 원으로 나누고 합계를 보존.
- 0~4명 단일 반 공헌이익, 계획 전체 등록률과 과정 수납액, 월별 예상 수납·제공 매출·손익·현금 변화·월말 잔액·월말 추가 필요자금, CSV.
- 기존 V55 승인 가격, V49 예산, V51 사용 상태 재료 단가를 한 번의 인증 요청으로 읽음. 가격 및 예산은 명시적 적용, 재료는 선택 추가. 기존 원본은 수정하지 않음. 실제 거래 및 아동·보호자 정보는 읽지 않음.
- 월 고정 현금비는 임대료·관리비·급여·사업주 보험·퇴직충당·대표자 건강보험 등의 예산 합계로 가정. 퇴직충당은 계획상 자금 확보액이지 실제 매월 납부액이 아님.
- 일반과세는 제공 매출에서 VAT를 제거하고, 확인된 고정비 매입 VAT를 빼서 손익을 계산. 간이과세는 VAT 납부 전 단순 추정. 재료비 매입 VAT 등은 별도 반영하지 않음. 월말 예상 잔액은 실제 계좌 잔액이 아니며 세금 실제 납부, 개원비, 대출, 체험/기타 매출, 일별 자금 부족을 제외. 환불·할인은 과정 전체에 선반영한 가정.

## 저장·권한
원장 + 재무 조회/쓰기 권한을 서버에서 확인. BW56_운영손익계획 시트에 단일 계획의 개정 행을 추가하며, 기존 데이터/공개 가격/계약/결제/재무장부는 변경하지 않음. 자료별 조회 권한을 추가 확인. 동일 저장 요청과 최신 행의 etag를 검사. 직접 시트 수정 시 동시 작업을 피하고 잘못된 JSON·헤더는 임의 복구하지 않고 중단. 시나리오별 별도 다중 저장 기능은 이 버전에 포함되지 않음.

## 설치
기존 Google 서버에 V55를 아직 설치하지 않았다면 V56 통합 ZIP 하나로 설치. 파일 12개, V55 설치 설명과 본 문서 포함.
이미 V55 설치했다면 동일 프로젝트의 StaffBridge.gs, StudioIntegrationV55.gs를 비교 교체하고 StudioPlanningV56.gs를 추가.
기존 코드, Script Properties와 시트를 백업. 직접 변경한 실운영 코드는 비교하여 보존.
원장 Google 계정의 직원용 Apps Script 편집기에서 setupBridgeWonderV55 실행: V56 모듈이 설치되면 BW56 계획 탭도 추가 생성. 이름은 이전 버전 호환을 위해 유지.
기존 직원 웹앱 배포 수정 → 새 버전 → 배포. 기존 /exec 및 실행 주체 유지. 공개 등록 프로젝트에는 설치 금지.
직원 홈 → 반별 손익 계획. 서버가 연결되지 않으면 기본 계산/CSV만 가능하며 저장·원본 불러오기는 비활성화. 설치 후 실제 연결을 점검해야 함.
