# Bridge Wonder V35 — 원더 홈페이지 이미지 및 Instagram 계정 전용 연결

## 적용 원칙

기존 브랜드 컬러와 테마, 로고·그림책·곰인형 일러스트를 변경하지 않고 배치만 조정합니다. 한국어 문장은 학부모가 읽기 쉬운 어투로 다듬습니다.

본 CSS는 `assets/css/site.css`에 이미 등록된 팔레트 정의를 그대로 이용합니다. 기존 테마 전체 교체나 사진 생성은 하지 않습니다.

## 가림·겹침 개선

- 메인 이미지: 중앙 로고·곰인형·그림책 이미지·하단 문구가 서로 겹치지 않도록 4개 행으로 나눕니다.
- 브랜드 철학: 기존 서로 겹치는 두 개의 일러스트 카드를 2열 정렬로 바꾸되 배경·테두리 색은 유지합니다. 폭이 360px 이하이면 1열로 전환합니다.
- 인스타그램 소개: 기울어진 두 장의 이미지가 서로 겹치지 않도록 정렬하고 계정 아이디는 전용 행으로 분리합니다.
- 스토리 페이지: 곰인형이 인용문에 걸치지 않도록 다른 열로 옮깁니다.
- 체험 페이지: 일러스트 세 장을 나란히 배치하고 하단 문구를 별도 행에 둡니다.
- 재료 카드: 모바일에서는 각 카드를 1열로 배치하여 제목·설명 잘림을 줄입니다.

## 인스타그램 계정 하나로 표시하는 무료 방식

**연동 대상:** `@bridgewonder.e` (공개 인스타그램 프로필)

**외부 결제 없음 / API 키 없음 / 각 게시물 주소 등록 없음.**

브릿지 원더 페이지의 `최근 게시물 보기` 버튼을 누르면 Instagram이 공식 제공하는 **프로필 임베드**를 불러옵니다.

- 계정이 공개 상태이고 Instagram의 임베드 기능이 활성화되어 있어야 합니다.
- 프로필 임베드는 Instagram 플랫폼 측에서 표시 내용을 결정하므로 최신 게시물 노출 개수·순서·디자인을 개별 커스터마이징할 수 없습니다.
- Instagram 측에서 특정 계정의 임베드를 제한하거나 방문자 브라우저가 스크립트를 차단하면 내장 프로필이 표시되지 않을 수 있습니다. 이 경우 공식 계정 열기 링크가 항상 남습니다.
- **Instagram Stories(24시간 스토리)는 프로필 임베드만으로 자동 재생되지 않습니다.** 스토리는 프로필 링크에서 확인하도록 안내합니다.
- 개인정보·서드파티 쿠키 보호를 위해 방문자가 버튼을 누르기 전에는 Instagram 임베드 스크립트를 불러오지 않습니다.
- 서버에서 Instagram 계정 데이터를 긁어오거나 비공식 크롤러를 사용하지 않습니다.

## 게시 위치
- `/sensory-studio/`: 메인 페이지에 '인스타그램에서 만나는 원더의 일상'
- `/sensory-studio/story/`: 브랜드 이야기 하단에 계정 임베드
- `/sensory-studio/programs/`, `/sensory-studio/experience/`, `/sensory-studio/visit/`: 이미지 겹침·테마 CSS만 적용

## 검증 방법
1. 메인과 스토리에서 `최근 게시물 보기`를 선택합니다.
2. 계정 URL이 `https://www.instagram.com/bridgewonder.e/` 하나로 설정됐는지 확인합니다.
3. Instagram의 공개·임베드 허용 상태에서 PC 브라우저/모바일 브라우저/시크릿 창으로 확인합니다.
4. 임베드가 차단되더라도 원본 계정 링크가 남는지 확인합니다.
5. 360, 375, 600, 840, 1020, 1440px에서 메인 로고·두 장의 카드·본문·모바일 버튼이 겹치지 않는지 확인합니다.
6. `npm run check`, `npm test`를 통해 소스·기존 시스템·신규 인스타그램 프로필 테스트를 실행합니다.

**실제 특정 Instagram 계정에 대한 임베드 허용 여부는 사이트 코드만으로 보장할 수 없으므로 브라우저 실사용 검증이 필요합니다.**

## V36 추가 개선 — 2026-11-20

### 버튼 없이 자동 표시
- 기존 `최근 게시물 보기` 버튼을 제거했습니다. `@bridgewonder.e` 공개 프로필을 표시하는 코드가 페이지에 기본 준비됩니다.
- 방문자가 해당 영역 근처로 스크롤하면 Instagram 공식 `embed.js`를 **자동으로 한 번 로드**합니다. 지원하지 않는 브라우저에서는 DOM이 준비되는 즉시 시작합니다.
- 불러오기에 성공하면 로딩 문구를 숨기고 Instagram이 제공하는 실제 게시물·릴스 프로필을 계속 표시합니다.
- 별도의 주기적 갱신이나 백그라운드 재호출은 하지 않습니다. 페이지를 다시 열면 새로운 프로필 내용을 요청하므로 인스타그램 계정의 최신 공개 게시물을 반영할 수 있습니다.
- **Instagram의 서비스 호출 횟수가 무제한임을 보장하지는 않습니다.** 이 구현은 Meta Graph API를 서버에서 호출하지 않지만, 방문자의 브라우저가 Instagram의 콘텐츠 서버에 요청하므로 Instagram 자체 정책, 요청 제한 또는 계정/브라우저 설정의 영향을 받을 수 있습니다.

### 화면 너비 개선
- 데스크톱에서는 2열 구조: 왼쪽 공식 계정 소개/브랜드 정보, 오른쪽 실제 Instagram 임베드(최대 약 540px)로 편집형 레이아웃을 구성합니다.
- 기존 임베드를 억지로 확대하면 내부 이미지가 늘어나거나 잘릴 수 있으므로, Instagram이 정한 비율을 보존합니다. 바깥 카드의 큰 흰 여백만 줄입니다.
- 태블릿/모바일에서는 한 열로 전환합니다. 작은 화면에서는 임베드 영역이 가로 스크롤을 허용하여 콘텐츠가 다른 문구 위에 겹치지 않도록 합니다.
- Forest/Sage/Ivory/Gold/Orange의 기존 색상 값은 바꾸지 않습니다.

### 비용 및 개인정보
- API 키·유료 위젯·게시물 주소 등록이 필요 없습니다.
- 인스타그램 미리보기가 화면 근처에 도달했을 때 Instagram으로 직접 접속하며, Meta가 방문자의 네트워크/기기 정보를 처리할 수 있습니다. 사이트 개인정보 안내와 운영 방침에 따라 외부 콘텐츠 제공 사실을 고지하는 것이 좋습니다.
- Instagram이 임베드를 막으면 공식 계정으로 연결하는 링크가 표시됩니다. 스토리 자동 재생은 지원하지 않습니다.

### 적용 확인
`/sensory-studio/` 와 `/sensory-studio/story/`를 새로 열어 인스타그램 영역까지 스크롤한 뒤 별도 클릭 없이 게시물이 표시되는지 확인하세요. 브라우저 새로고침만으로 기존 JS가 다시 사용되지 않도록 JS/CSS 버전을 `36.0.0`으로 올렸습니다.
