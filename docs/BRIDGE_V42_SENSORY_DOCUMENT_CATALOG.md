# Bridge Wonder V42 — Sensory Studio 문서센터

## 범위
- 직원 전용 GitHub Pages `/staff/`, `/staff/standalone.html`에서만 적용.
- 기존 V41 상단 카테고리와 4색(#40543A, #99A682, #FBF8F2, #D1693B)은 그대로 유지.
- 원본 보호자 신청·전자서명 계약, 문서 이력, Google Apps Script, Google Sheets, 로그인·권한, PDF 발급·이메일 발송 프로토콜을 수정하지 않음.
- 새 서식은 **준비 중**으로 표시하고 발급 버튼을 제공하지 않음. 프런트 화면에 건강정보, 아동 개인정보, 서명정보를 새로 수집하거나 저장하지 않음.

## V42 문서목록
| 영역 | 기존 서버로 발급 가능한 문서 | 별도 구현·법률 검토가 필요한 서식 |
| --- | --- | --- |
| 상담·체험 | 상담 접수 확인서 | 체험 예약 확정 안내, 상담 결과·이용 안내 |
| 이용 신청·보호자 동의 | 없음 | 이용 신청서, 이용·취소·환불 조건 확인서, 아동 개인정보 처리 안내·동의서, 사진·영상 선택 동의서 |
| 클래스·안내 | 클래스 안내문, 일반 안내문 | 일정 변경·휴강 안내, 오감놀이 준비물 안내 |
| 이용료·환불 | 납부 내역 안내서 | 환불 처리 안내서, 실제 결제수단의 영수증 |
| 영유아 안전·운영 | 기존 재료·안전 점검 메뉴에서 업무기록 | 재료·안전 안내, 보호자 인계, 비상연락, 독립 PDF 점검표, 사고·특이사항 보고서 |
| 기존 계약·등록 원본 | 기존 수강 등록 확인서, 기존 전자서명 계약서 사본 | 두 문서를 새 스튜디오 이용 신청·동의서로 대체하거나 법적 의미를 변환하지 않음 |

새로 표시된 항목은 실제 문서발급 기능이 아니라 **향후 개발할 서식 목록**. 기존 PDF 발급에 사용하는 서버 문서 유형 ID
`inquiry`, `registration`, `payment`, `class`, `contract`, `notice`를 변경하지 않음.
역할에 따라 문서 선택 옵션은 기존 백엔드에서 제공하는 허용 목록에 따라 결정.

## 법적 유의사항
- 교육서비스업으로 사업자등록을 하더라도 학원법 적용 여부는 **실제 모집·교습·반복 운영 방식**과 관계기관 판단에 따라 달라질 수 있음. 세무상 업종 변경만으로 기존 법정 의무가 사라지는 것이 아님.
- 특히 기존 `registration` PDF는 Apps Script `Code.gs`의 학원 등록번호·교습비 필수 필드를 요구하므로, 학원형 원본을 그대로 신규 교육서비스 이용 신청 확인서로 발급해서는 안 됨.
- 만 14세 미만 아동의 개인정보 처리를 위해 동의를 받는 경우에는 법정대리인의 동의·확인 절차가 필요. 사진·영상 활용 동의는 필수 이용동의와 분리하고 철회 절차를 마련.
- 현금영수증·카드전표 등은 실 결제수단에 따른 정식 증빙 발급 기능과 분리.
- 환불 기한 및 방식은 실제 계약·적용 법령에 따라 검토. 기존 환불 원장과 기록 수정 없음.
- 의료·건강·알레르기·사고의 상세정보는 일반 문서목록·공지사항 입력창에 적지 않도록 관리.

## 배포·검증
- 추가 파일: `assets/js/staff-documents-v42.js` (프런트 문서목록, 스타일, DOM 감시).
- GitHub 직원 페이지 2곳에서 V33 메뉴 스크립트 이후 V42 스크립트를 불러오도록 구성.
- V42는 신규 서버 호출·브라우저 저장·비공개 자료 복제 기능이 없음. 기존 서버는 계속 사용.
- `node tests/staff-documents-v42.test.cjs`; `npm run check`; 기존 V41 포함 전체 회귀 테스트.
- 사이트 반영 확인: https://bridgewonder.bridgeacademy.co.kr/staff/
- **Google Apps Script 재설치 및 함수 실행은 필요 없음.** 새 동의서의 실제 생성·서명·PDF·이메일 자동화는 별도 백엔드 업데이트 후 가능.
