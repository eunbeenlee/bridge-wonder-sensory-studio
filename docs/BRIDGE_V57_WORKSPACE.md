# Bridge Wonder V57 · 전체 직원 워크스페이스 통합

V56의 반별 손익·운영계획을 포함합니다. 직원 메인과 독립 업무 화면 8개에 권한 기반 공통 업무 바로가기를 연결했습니다. 메인은 기존 상단 업무 분류를 유지하고, 독립 자료와 원장 도구를 보조 메뉴로 제공합니다. 캐릭터 이미지와 외부 라이브러리 추가 없음.

## 안정성과 속도
- 운영자료 목록은 50개씩 표시하고 검색 입력을 짧게 묶어 처리. 서버 확인 응답의 항목만 즉시 반영하고 다음 동기화에서 전체 목록 확인. 변경 없음 응답에서는 불필요한 목록 렌더를 하지 않음.
- 운영자료의 저장 요청 식별자를 같은 내용의 재시도에 재사용. 새 행 ID를 요청 ID에 연결하여 동일 요청으로 새 행이 중복 생성되지 않도록 방어. 다른 내용의 요청 재사용 거부. 감사 기록 실패는 저장 자체의 실패로 표시하지 않고 경고.
- 재무 입력 중 조회 월 전환/다른 업무로 이동할 때 확인. 예산 수정 중 거래 목록을 갱신해도 예산 입력을 보존. 거래 테이블은 실제 조회 시에만 다시 생성. 같은 저장 내용의 재시도에 같은 요청 키 사용.
- V55 요금 및 V56 계획의 미저장 이동 확인. 기존 로그인·원장 권한 확인 유지. 시트 구조 불일치 시 덮어쓰기 금지.
- 모바일 업무 메뉴·긴 금액 및 좁은 입력 영역 개선. 기존 4대보험 수치와 계약·결제 데이터는 변경하지 않음.

## 설치
Google 프로젝트를 아직 갱신하지 않은 경우 V57 통합 설치 ZIP의 12개 파일을 기존 **직원용** Apps Script 프로젝트에 적용. 기존 코드/Script Properties/연결 시트 백업 후 비교하여 운영 중 변경을 보존. 이미 V56 서버 설치를 마쳤다면 StudioContentV51.gs와 StudioFinance.gs 변경분을 비교 적용하면 됩니다. 신규 설치 시 원장 Google 계정으로 편집기에서 setupBridgeWonderV55 실행(이름은 호환성을 위해 유지), 기존 웹앱의 배포를 새 버전으로 수정. /exec와 권한을 유지. 공개 등록 프로젝트에는 설치하지 않음. 실제 서비스 저장·조회·권한을 샘플로 점검. 기존 V55/V56 안내도 함께 참고.

Google 실서버와 실제 데이터는 GitHub 배포만으로 변경되지 않음. 실서버 적용 전 새 저장 기능은 계산/조회 가능 범위 내에서만 동작. 기본 V54 요금 10주 320,000원, 최대 정원 4명 및 기존 기록 유지. 자동 테스트는 모의 시트와 브라우저 DOM을 사용하며 실제 사용 기기 체감 속도/시트 연결 측정은 별도로 필요.
