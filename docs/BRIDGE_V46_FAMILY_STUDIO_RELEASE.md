# Bridge Wonder V46 — 7~48개월 보호자 참여형 수업과 수업안 자료실

적용 범위: 공개 센서리 스튜디오 홈페이지 및 직원용 정원 서버 검증. **기존 V45 직원 수업안 업로드 기능은 그대로 유지합니다.**

## 1. 확정한 운영 기준
- 대상: **생후 7~48개월**.
- 한 회차: **아이 최대 4명**, 아이 한 명당 보호자 한 명 동반. 부모·보호자가 수업 **50분 내내 참여**하며 아이만 맡기는 분리수업은 하지 않습니다.
- 정규 회당 50분 30,000원, 체험 회당 50분 25,000원(안내가 기준). 할인·재료비·부가세·환불 조건은 실제 신고·세무 및 이용조건 검토 후 확정합니다.
- 회차 4명은 운영자가 정한 **아이 정원**이지 학원법상 등록 제외나 건축·소방상 적정 수용 인원에 대한 법적 결론은 아닙니다. 보호자 4명과 진행 교사, 동시에 운영하는 다른 공간을 별도로 확인해야 합니다.

## 2. 공개 사이트 변경
- `/sensory-studio/`, `/programs/`, `/experience/`, `/visit/`, `/story/`: 한 타임 아이 4명 + 보호자 동반 안내를 공통 카드로 표시. 기존 브랜드 색감·로고·가격·체험·상담 흐름은 유지.
- 방문/문의 FAQ: 보호자가 활동 내내 함께한다는 점과 회차별 참여 인원 명시. 상담 신청은 예약 확정·결제와 분리.
- 기존 `/sensory-studio/enroll/`: **신규 온라인 수강계약·전자서명 입력을 잠시 중단**하고 체험·클래스 상담 안내로 연결. 예전 계약서 PDF·Sheets·원본 코드·수납 내역을 삭제하거나 수정하지 않음.
- `/sensory-studio/privacy/`: 현재 상담 접수와 과거 수강등록 보관 기록을 구분. 개인정보처리자 명칭·위탁·보유기간 등 최종 개인정보 처리방침은 실제 운영자 확인이 필요.
- `/index.html` 및 오픈 안내 팝업: 7~48개월, 아이 4명, 보호자 참여 안내로 통일.

## 3. 직원 사이트 수업안 자료실 (기존 V45 유지)
- 직원 사이트 `/staff/` → **오감놀이 준비 → 월간 오감놀이 계획 → 수업안 파일**
- 서식은 정하지 않아도 됩니다. 파일 1개만 필수이며 제목·적용 월·대상 월령·메모는 선택입니다.
- 지원: PDF, DOCX, XLSX, PPTX, HWP, HWPX, PNG/JPG, TXT, CSV, 1개 최대 **5MB**
- 원장·관리자: 신규 업로드, 수정본 버전 추가, 정보 수정, 보관/복구, 다운로드
- 선생님: 사용 중인 자료 열람·다운로드. 상담 담당자: 열람 불가
- 원본은 Google Drive 비공개 폴더에 저장, 문서 이력은 비공개 Sheets에 보관. 파일이 공개 홈페이지에 올라가거나 공개 Drive 링크로 공유되지 않음.

**실제 업로드 작동 조건:** 직원용 Apps Script에 `LessonPlans.gs`와 관련 `StaffBridge.gs`가 설치·배포되어 있어야 합니다. 기존 V45 파일 자료실은 GitHub 화면만 반영해도 실제 파일을 저장할 수 없습니다.

## 4. 직원용 정원 서버 업데이트 (V46)
- 관리자 UI는 이미 한 타임 4명 정원과 과거 4명 초과 설정에 대한 경고를 제공합니다.
- V46의 `Code.gs`는 **앞으로 저장하는 정원만 1~4명으로 검사**합니다.
- 과거 반 정원·수강 기록은 자동 변경하지 않으며, 기존 4명 초과 정원은 운영자가 개별 확인해야 합니다.
- 신규 저장에는 서버 재배포가 필요합니다.

### 설치 패키지
- `Bridge_Wonder_V46_Staff_Family_And_Lesson_Upload.zip`에는 기존 직원용 **Code.gs, StaffBridge.gs, LessonPlans.gs**만 포함합니다.
- 기존 직원용 프로젝트의 해당 파일을 백업하고 교체(없던 LessonPlans.gs는 추가)한 뒤, **기존 직원 웹앱 /exec 배포를 새 버전으로 업데이트**합니다.
- Payroll.gs·기존 시트·계정·비밀번호·수강등록 원본·공개용 Apps Script는 변경하지 않습니다.
- 별도 설치 함수 실행은 필요하지 않습니다. 서버 설치 전에는 현재 V45 자료실의 실제 업로드가 실행되지 않습니다.
- 설치 후 허구의 소형 PDF 업로드·다운로드·수정본 등록, 반 정원 5명 거부·4명 저장을 확인합니다.
