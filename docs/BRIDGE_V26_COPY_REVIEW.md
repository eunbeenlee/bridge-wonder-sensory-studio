# V26 공개 웹사이트 문구 정리

검토일: 2026-11-20 (한국시간)

## 반영 범위

브랜드 선택, 원더 홈, 브랜드 이야기, 프로그램, 체험, 방문·문의, 수강 등록, 개인정보 안내, 아카데미 준비 안내, 404 및 이전 주소 이동 페이지를 검토했습니다. 공개 HTML 11개와 화면 안내 JavaScript 4개의 문구를 다듬었습니다.

기존 아이보리·세이지 계열 테마, 공식 로고, 이미지, 레이아웃, 링크, 폼 항목과 값, 접수·등록 로직은 유지했습니다. 사이트 CSS와 이미지 파일은 수정하지 않았습니다.

## 문구를 다듬은 기준

- 겹치는 표현과 어색한 문장 구조를 정리했습니다.
- 프로그램 설명에서는 아이의 월령·발달과 선생님의 상호작용 관계가 명확하게 드러나도록 했습니다.
- 버튼과 처리 결과는 보호자가 다음에 할 일을 알 수 있게 다듬었습니다. 접수 확인 전에는 성공을 단정하지 않는 기존 동작을 유지했습니다.
- 사용자에게 불필요한 내부 구현 표현은 접수·보관 상태를 설명하는 말로 바꿨습니다. 개인정보 처리 안내의 Google 서비스 명칭과 운영 전 확인 항목은 유지했습니다.
- 연락처·장소·비용·대상 월령·수업 시간·운영 일정·동의 범위는 새로 만들거나 바꾸지 않았습니다.

## 검증 결과와 범위

- 변경된 공개 HTML 11개를 이전 버전과 비교해 요소 순서, 구조, CSS 클래스·스타일, 링크, 폼 이름·값의 동일성을 확인했습니다. 설명 문구를 담는 메타데이터 등은 비교에서 제외했습니다.
- `site.css`와 로고·이미지 자산의 변경이 없음을 확인했습니다.
- 변경한 JavaScript 4개 모두 `node --check` 문법 검사를 통과했습니다.
- 공개 웹사이트 문구 변경은 결제·예약·이메일 발송을 실행하지 않았습니다.
- 이 문구 검토 단계에서 Chromium 실행을 시도했지만 실행 환경의 소켓 권한 제한으로 브라우저가 시작되지 않았습니다. 따라서 이 문서 자체는 모바일·데스크톱 시각 검증 완료를 주장하지 않습니다. 통합 QA에서 별도로 확인한 결과가 있다면 통합 보고서를 기준으로 합니다.
