# Bridge Wonder V31 — GitHub 중심 직원 포털 통합·사용성 개선

## 현재 상태
**검증 브랜치에서 개발·검증 중이며 실제 사이트나 Google Apps Script 운영 배포는 변경하지 않았습니다.**

V30의 이메일 직원 로그인, 원장 권한 관리, 임시 비밀번호 발급, 본인 비밀번호 변경 기능에 V31 직원 화면 개선을 누적했습니다. 운영 적용은 V30+V31을 한 번에 진행할 수 있도록 준비했습니다.

## 시스템 책임 분리 — GitHub 우선
1. **GitHub Pages (브라우저 화면의 단일 기준)**: 원장·선생님 포털 HTML/CSS/JavaScript, 메뉴 및 드롭다운, 프런트엔드 검증, 사용 순서 안내, 문서 미리보기.
2. **Google Apps Script (사설 업무 API/신뢰 경계)**: 이메일·비밀번호 검증, 세션 발급 및 만료, 서버 역할/메뉴 권한검사, 개인정보 조회/저장/수정, PDF 생성·발송. `StaffBridge.gs`의 명시된 업무 목록만 호출.
3. **Google Sheets (데이터 저장소)**: 직원, 강의실/수업반, 상담, 등록, 출결, 수납, 운영기록. **직원 브라우저에서 Google Sheets를 직접 열거나 데이터 접근 키를 다운로드하지 않습니다.**
4. **Google Drive (비공개 원본/발급문서 저장소)**: 계약서, 급여명세서, PDF. URL·문서 권한은 서버가 확인합니다.

GitHub Pages는 **정적 호스팅**이므로 로그인 서버나 안전한 데이터베이스를 대신할 수 없습니다. 기존처럼 Apps Script로 조회와 쓰기를 모두 수행하되, 화면 이동·선택·필터링에는 Google 왕복 호출을 하지 않는 구조가 정확합니다.

## V31 개선 내용
- **메뉴 3그룹**: `수업·출결`, `상담·등록`, `운영·직원 관리`로 묶어서 펼치기·접기. 해당 권한 없는 메뉴는 보이지 않으며 서버에서도 차단됩니다.
- **상단 업무 선택 드롭다운**: 화면 상단에서 허용된 업무로 이동. 모바일 기존 `업무 선택` 드롭다운도 같은 3그룹으로 표시.
- **각 화면에 짧은 사용 순서**: 출결·보강·상담·문서·직원 계정 등 저장 버튼까지의 실제 순서 제시. 기능이 아니라 도움말로만 동작하므로 데이터 변경 없음.
- **수업반 생성 드롭다운**: 원장에게도 요일, 과정, 공개 여부, 검토 상태를 자유입력식 `datalist` 대신 유효한 `select`로 제공. 반 코드 자동 제안과 기존 수업 시간·교습 기간 선택 유지.
- **고급 항목 축소**: 수업반 코드/과정/공개 설정, 직원 연락처·담당 반 지정, 직원별 세부 권한은 필요할 때 펼침. 기본값/서버 검증은 유지.
- **운영점검 검색**: 카테고리 외에 진행 상태 드롭다운·제목 검색을 추가. 이미 불러온 카드만 필터링하므로 새 Google 호출 없음.
- **수강생 명단 수업반 필터**: 이미 받은 명단을 클라이언트에서 빠르게 축소.
- **직원 준수사항**: 직원별 선택 드롭다운으로 한 사람의 확인 항목만 표시.
- **월간 주제**: 연령대별 세부 진행 방법을 기본 접기.
- **발급 문서 이력**: 기본 접기.
- **로그인 도움말**: 기존 '첫 로그인', '비밀번호 재설정'을 도움말 안에 정리. 원장 임시 비밀번호 발급 기능을 우선 노출.

## 성능 규칙
- **GitHub UI 즉시 렌더링**: 메뉴와 입력 컨트롤은 브라우저가 표시하고 이동 시 서버 템플릿 재생성이 필요 없습니다.
- **필요할 때 조회**: 클릭한 페이지에서만 비공개 자료를 서버에서 요청. 초기 로그인에 출결·수납·급여를 일괄 조회하지 않음.
- **조회 중복 통합**: 기존 `administration-accelerator.js`의 동시 요청 합치기 및 단기 메모리 캐시 유지.
- **개인정보 캐시 최소화**: 직원/아동/보호자 개인정보를 브라우저 영구 저장소에 캐시하지 않음.
- **서버 최종 검증**: UI의 드롭다운/메뉴 숨김은 편의 기능이며, 인증·권한·저장 검증은 Apps Script가 집행.
- **속도 측정**: Google 서버 왕복과 WebCrypto 시간 분리. 8초가 전부 화면 처리 때문이라고 가정하지 않음.

## 적용 보류 — 일괄 배포 체크리스트
1. 현재 운영 중인 Google Apps Script 직원 프로젝트의 기존 `Code.gs`, `StaffBridge.gs`, `Admin.html` 백업.
2. 기존 데이터/급여 스프레드시트와 Script Properties의 비밀번호 pepper, 스프레드시트 ID는 **유지**.
3. V30·V31의 직원 Google Apps Script 코드 업그레이드, 기존 `/exec` URL의 새 버전으로 **재배포**.
4. 바로 이어서 GitHub PR #12 병합. 배포 중간에는 신규 화면을 직원에게 공개하지 않음.
5. 원장 로그인 → 직원 생성/임시 비밀번호 발급/직접 변경 → 메뉴 권한 검증 → 수업 시간표·상담·등록·출결·수납·급여 읽기 검증 → 기존 기능 보존 확인.
6. 실제 Google 서버 성능·브라우저 실사용 검증 후 속도 전/후를 측정.

## 테스트 명령
- `npm run check`: HTML/JS/GS 문법·로컬 리소스·레이아웃 빌더 동기화
- `npm test`: 급여, 등록, 역할권한, 보안, 로그인, V30 임시 비밀번호, V31 화면 사용성 회귀 검증

**현재 개선은 데이터 모델·시트 구조를 변경하지 않습니다. V30 직원 계정 API 외에 V31용 신규 Apps Script API를 추가하지 않았습니다.**
