# Bridge Wonder V43 — 교육지원서비스업·센서리 스튜디오 법적 사전 검토
기준일: 2026-11-21
사업 전제: 부산 강서구 명지 2층 상가 2-75호, 만 7~48개월, 영어 표현을 활용한 감각놀이, 정규 50분 30,000원 / 체험 50분 25,000원.

**결론:** 교육지원 서비스업으로 사업자등록을 검토하더라도 학원법 적용 제외가 확정된 것은 아닙니다. 업종 선택과 시설별 등록·신고 여부는 실제 운영에 따라 따로 판단해야 합니다. 관할기관의 서면 확인 전에는 비대상·면세·신고 불필요라고 광고하지 않습니다.

## 1. 핵심 쟁점
- 한국표준산업분류 85709 '기타 교육지원 서비스업'은 다른 교육과정이나 교육시스템의 지원 서비스입니다. 유학 알선·교환학생 프로그램이 예시로 제시됩니다. 아이들에게 직접 놀이·영어 활동을 제공하는 브릿지 원더와 맞는 분류인지 반드시 세무서에 확인해야 합니다.
- 현행 학원법 제2조에는 불특정다수 또는 법정 인원 이상의 학습자 대상 30일 이상 교습(반복 포함)이 규정되어 있습니다. 시행령상 동시 교습 인원 기준은 원칙적으로 10명입니다. 인원이 9명이라고 하여 무조건 제외되지는 않습니다.
- 대법원은 과거 주 1회 오감놀이·창의력 프로그램도 실제 교습 내용에 따라 학원법 적용 대상으로 보았습니다. '체험', '스튜디오', '놀이'라는 명칭만으로는 결론이 나지 않습니다.
- 영아·유아가 혼재된 7~48개월 대상, 영어활용 정도, 정기수업, 반별 정원, 보호자 동반 여부, 강사의 지도내용을 적어서 **북부교육지원청 051-330-1291~1295**에 문의해야 합니다.
- 보호자가 아이를 맡기고 떠나는 방식은 보육·돌봄 관련 규제도 검토해야 합니다. 부모가 참여하는 1회 감각체험으로 운영하더라도 자동으로 면제되지 않습니다.

## 2. 기관별 확인
1. **북부교육지원청**: 수업 방식, 주 1~2회 반복, 대상 월령, 영어활동, 인원·보호자 동반 여부를 제시해 학원·교습소 해당 여부 및 필요한 교습과정 확인.
2. **세무서**: 희망 업종 85709의 적합성, 다른 가능한 분류, 부가세 과세·면세, 가격의 부가세 포함 여부. 교육지원업 등록만으로 교육 용역 면세가 자동 발생하지 않으며, 부가가치세법 시행령 제36조의 시설·인가·등록 요건이 별도로 적용됩니다.
3. **구청 건축부서·소방서**: 실제 건축물대장상 용도, 2층 상가의 바닥면적, 가벽, 건물 관리규약, 피난 통로 및 시설 안전. 이전 학원안의 강의실 최소면적을 현 업종에 그대로 적용하지 않습니다.
4. **구청 위생·안전 담당**: 재료를 '만지기용'과 '먹기용'으로 구분. 음식 조리·판매·제공이 있으면 식품위생법 해당 여부 검토. 놀이기구·놀이공간에 어린이놀이시설법이 적용되는지 확인. 2027-02-28부터 시행되는 개정 조항도 별도 확인.
5. **결제·소비자보호**: 체험/정기권의 취소·환불 규칙, 계속거래 해지, 온라인 예약·선결제 시 통신판매 신고 해당 여부 및 영수증 발행.
6. **개인정보**: 만 14세 미만 아동 개인정보의 동의가 필요한 처리에 법정대리인 동의·확인. 홍보사진·영상 동의는 별도 선택. 건강·알레르기 정보는 일반 상담 메모 대신 접근을 제한한 별도 경로에서 처리.

## 3. 사업 운영과 기존 시스템
- 정규 50분 30,000원 / 체험 50분 25,000원: 실제 결제가격, 재료비 포함 여부, 할인 중복, 부가세 포함 여부 확정 후 동일하게 안내합니다.
- 월 2회 실제 식재료 + 월 2회 자연소재를 사용하는 계획에는 월령별 질식·삼킴 위험, 위생, 도구 적합성 확인이 필요합니다.
- 기존 Google Apps Script 문서 유형 6종은 그대로 유지. 학원등록번호를 요구하는 등록 확인서 및 기존 계약 PDF를 교육지원업의 신규 동의서로 간주하면 안 됩니다.
- 기존 서버 환불대장은 사유 발생일+5일로 계산합니다. 이 숫자를 새로운 서비스의 법정 환불기한으로 사용해서는 안 됩니다. 이용권 정책이 확정된 후 서버 기능을 별도로 설계합니다.
- 기존 학원용 점검 항목은 과거 기록으로 유지하고 V43의 별도 '적용 여부 확인' 목록으로 구분합니다.

## 4. 관할 교육지원청에 전달할 문의문
제목: 부산 강서구 영유아 오감놀이 체험공간의 등록 요건 사전 문의

안녕하세요. 부산 강서구 명지의 2층 상가에서 영유아(7~48개월) 대상 오감놀이 공간을 준비하고 있습니다. 활동 시간은 회당 약 50분이며, 영어 표현을 활용한 감각놀이와 1회 체험·주 1~2회 정기 프로그램을 계획하고 있습니다. 교육지원 서비스업 형태로 사업자등록을 검토 중이지만, 실제 운영에 맞는 등록·신고 요건을 먼저 확인하고자 합니다.

첨부할 활동계획서, 주간 시간표, 반별 정원, 보호자 동반 방식, 교구 및 공간 평면도를 기준으로 학원·교습소 해당 여부와 시설·교습과정 기준을 안내 부탁드립니다. 비대상으로 판단되는 경우에도 판단 사유와 추가로 확인할 기관이 있으면 알려주시면 감사하겠습니다.
