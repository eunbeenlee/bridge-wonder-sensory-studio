# Bridge Wonder V16 — 공통 온라인 등록 (GitHub 덮어쓰기)

## 변경된 흐름

상담 문의와 수강 등록은 별도 페이지입니다. 현장 상담 후 모든 보호자에게 **같은 링크**를 안내합니다.

https://bridgewonder.bridgeacademy.co.kr/sensory-studio/enroll/

보호자는 `과정 → 시작일 → 요일·시간`을 드롭다운으로 선택합니다. 수업조건·교습비·반환 기준은 직원이 사전 승인한 값만 표시됩니다. 보호자 성명, 연락처, 이메일, 아동 이름·주소는 직접 기입해야 하며 필수·선택 동의는 항목별 체크박스, 전자서명은 별도로 유지됩니다.

**공개 전 주의:** Apps Script를 먼저 V16으로 올리고 `setupPublicEnrollmentV16`을 실행한 다음 수강반을 승인하세요. 승인 수강반이 없으면 폼이 잠기며, 임의의 금액이나 운영정보를 표시하지 않습니다.

## 설치

1. 현재 **Bridge Wonder GitHub 저장소**를 백업하세요. Bridge Academy 저장소는 수정하지 않습니다.
2. 이 ZIP의 내부 파일·폴더를 Bridge Wonder 저장소 최상위에 덮어쓰세요 (`.git` 폴더는 유지).
3. `Commit to main` → `Push origin`.
4. 시크릿 모드 또는 새로고침(Ctrl+Shift+R)으로 위 공통 등록 주소를 여세요.
5. `방문·문의` 페이지에서도 **상담 후 온라인 수강 등록** 링크를 사용할 수 있습니다.

### 이전 코드 링크 호환성

이전에 발급한 `?code=...` 등록 링크는 기존처럼 사용할 수 있도록 유지했습니다. 새로 상담한 보호자에게는 코드를 발급할 필요가 없습니다.

### 확인해야 할 사항

- 기존 Google Sheets·PDF·자동백업은 유지됩니다. 파일을 배포했다고 기존 기록을 삭제하지 않습니다.
- 실제 Google 계정의 PDF 생성·이메일 알림·시트 기록은 **테스트 등록 1건으로 확인해야** 합니다.
- 공통 등록 링크는 누구나 열 수 있습니다. 상담 이력과 등록 조건·법정대리인 확인·영수증 발급은 직원이 최종 점검한 뒤 확정 처리하세요. 무단 제출이나 반복 스팸이 발생하면 추가 인증이 필요할 수 있습니다.
- 학원 등록사항, 교습비·반환 기준, 개인정보 처리 및 동의 문구는 운영 정보와 관계 법령에 맞춰 확정해야 합니다. 본 패키지로 법적 적합성이 자동 보장되지는 않습니다.
